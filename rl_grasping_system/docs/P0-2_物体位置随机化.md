# P0-2 物体位置随机化 + 全链路可复现（seed）

## 一、目标

P0-1 验证了单点（`(0.5, 0, 0.1)`）物理抓取可行性。P0-2 在此基础上：

1. **物体初始位置随机化**：让物体在可抓取的工作空间内随机摆放（而不是每次固定在 `(0.5, 0)`），为后续 RL 训练提供多样性；
2. **目标位置与物体实际位置同步**：修复 `target_pos` 硬编码 `(0.5, 0, 0.3)` 与真实物体落定高度 `z≈0.02` 不一致的隐性 bug；
3. **全链路可复现**：物体位置 + 初始机械臂位形都由 `reset(seed)` 决定——同一 seed 复现完全相同的初始状态，不同 seed 得到不同初始状态。

## 二、改动内容

### 1. `config.py`（`GraspingConfig`）

| 字段 | 值 | 说明 |
|---|---|---|
| `use_fixed_position` | `True` | 语义修正：`True` = 固定桌面位置 `(0.5, 0)`；`False` = 在 `workspace_bounds` 的 X/Y 内随机（此前该字段存在但从未被消费） |
| `object_rest_z` | `0.02` | 物体落定高度（= 0.04 m 立方体半边长；P0-1 实测自由落体落定 `z≈0.0199`）。X/Y 随机或固定时 **Z 都用此值**，物体直接放在桌面上，避免落体漂移 |

采样范围复用已有的 `workspace_bounds = ((0.3,0.7), (-0.2,0.2), (0.05,0.3))`：只取 X/Y 两个维度，Z 不用（由 `object_rest_z` 决定）。

### 2. `environment.py`

- 新增 `_sample_object_position()`：
  - `use_fixed_position=True` → 返回 `(0.5, 0, object_rest_z)`；
  - `use_fixed_position=False` → 从 `self.np_random` 在 `workspace_bounds` 的 X/Y 内采样，Z 固定 `object_rest_z`。
  - 随机数取自 `self.np_random`，因此**完全由 `reset(seed)` 决定**。
- `reset()`：
  - 初始位形改为 `generate_safe_initial_config(self.np_random)`——机械臂初始位形也进入可复现链路；
  - 用 `_sample_object_position()` 采样物体位置后调用 `_set_object_position()`；
  - 调整顺序：`mj_forward` 之后再读取物体位置（修复此前 `task_state['object_position']` 读到上一 episode 陈旧 `xpos` 的问题）；
  - **`self.target_pos = 物体实际位置`**（`xpos`），并同步 `task_state['object_position']`——观测/奖励里的目标位置从此与真实物体位置一致。
- `_set_object_position()` 的默认落点从 `(0.5, 0, 0.1)` 改为 `(0.5, 0, object_rest_z)`。

### 3. `singularity_handler.py`

- `generate_safe_initial_config(self, rng=None)`：新增 `rng` 参数；传入时用 `rng.uniform(...)`（可复现），`None` 时回退全局 `np.random`（兼容旧调用）。
- 这是全库唯一一处 `np.random` 使用点，替换后 reset 链路内不再有隐式全局随机。

## 三、验证

### 1. 环境级验证（P0-2 行为）

在 `rl_grasping_system/` 下运行临时测试（见下文复现步骤）结果：

```
reset(42) 两次物体位置一致: True        # 物体位置可复现
reset(42) 两次初始位形一致: True        # 初始位形可复现
  obj1 = [0.6144 -0.1488 0.02]
reset(42) vs reset(43) 位置不同: True   # 不同 seed 不同
target_pos = [0.4055 -0.032 0.02]  物体实际 = [0.4055 -0.032 0.02]   # 目标位置已同步
seed 42-61 共 20 个随机位置全部落在 bounds X/Y 内且 Z=0.02
观测中 target_position = [0.6144 -0.1488 0.02]  实际 = [0.6144 -0.1488 0.02]  # 观测同步
ALL PASS
```

### 2. 纯 MuJoCo 验证脚本

`scripts/verify_position_randomization.py`（纯 MuJoCo，不依赖 RL 环境代码）：

- 固定 seed 采样 N=20 个位置，逐个做**抓取位姿 DLS-IK 可达性校验**（复用 P0-1 的 `solve_ik`）；
- **抽查 3 个代表位置**（距底座最近/中/最远）完整执行 张开→下降→闭合→抬升；
- 结果写入 `scripts/position_randomization_result.json`。

运行：

```bash
cd rl_grasping_system
python scripts/verify_position_randomization.py --seed 2026 --n 20
```

### 3. 与 P0-1 回归

- 物体仍可被抓取抬升（P0-1 `verify_grasp_feasibility.py` 逻辑未变，随机化脚本中的完整抓取即复用该流程）；
- 若随机采样到不可达位置，脚本会输出 `unreachable_positions` 并返回非 0——用于指导收紧 `workspace_bounds`。

## 四、使用说明

```python
env = PandaGraspingEnv(grasping_config, reward_config)
# 随机模式（训练用）：
grasping_config.use_fixed_position = False
obs, info = env.reset(seed=42)     # 每次 reset(seed) 复现同一初始状态；换 seed 换初始状态
# 固定模式（调试/复现用）：
grasping_config.use_fixed_position = True
env.reset(seed=42)                 # 物体永远在 (0.5, 0, 0.02)，位形仍由 seed 决定
```

- 物体初始位置：`env.data.xpos[env.object_id]` 或 `env.task_state['object_position']`；
- 目标位置（观测/奖励用）：`env.target_pos`（reset 后与物体实际位置一致）。

## 五、已知限制

- 随机范围与 `workspace_bounds` 一致，但**边界附近（尤其 `x=0.7, y=±0.2`）可能超出 IK 可达域**；验证脚本会把不可达位置打点输出，训练前建议按实测可达域收紧 `workspace_bounds`。
- 初始位形随机范围是保守的"安全区间"，与物体位置无关（未做"针对物体位置的初始位形规划"），仅保证无奇异、不保证物体在视野正前方——P0-2 只要求可复现 + 随机，不要求视野规划。
