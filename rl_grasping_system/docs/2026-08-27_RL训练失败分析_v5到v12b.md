## 2. 每版失败机制（深层根因）

### v5：无惩罚梯度 → 策略根本不感知碰撞
- 训练 `collision_penalty=0`，RL 只有抓取奖励信号 → 最优策略 = 无视障碍直奔目标。
- **证据**：碰撞率 98-99.5%，平均 45-60 次碰撞/episode；残差幅度成功/失败几乎无差
  （0.2163 vs 0.2162）——每步残差恒定，说明策略从未把障碍当输入。
- **教训**：无信号则无行为。碰撞率不是"顺带"能学出来的。

### v6：当步惩罚太弱 → 奖励经济学穿障划算
- penalty -2/步：成功 +100 主导，碰 15 次也只 -30 → **穿障净赚**。
- **证据**：63% 的成功 episode 仍带碰撞（平均 15 次）；碰撞率 65.5%（v5 减半但远未归零）。
- **关键机制**：`-2×15=-30` vs `+100` → RL 的理性选择就是穿障。这是**奖励设计**问题，不是感知问题。

### v7/v8：加强惩罚 → 伤成功率、碰撞不降
- penalty -5 + max_streak 30：成功率 79%→69.5%（掉 10pp），碰撞率 64%（≈v6）。
- 侧偏随机 ±6cm：碰撞率仍 ~57%。
- **教训**：在"感知未激活"（见 v11 探针）的前提下，调惩罚强度只会伤抓取。

### v9/v10：从零学 → 避障主导、抓取崩 —— 证明"多任务同时学"存在基本矛盾
- **v9（从零 300k）**：碰撞率 7.5%（学会避障），但成功率 0.5%（够不到，final_dist 0.69-0.76m）。
- **v10（续训 500k）**：成功率 2-5%（final_dist 中位 0.53m，94% episode 够不到）。
  **注**：v10 的 warm-start 曾因 `--load-model` 文件名路径 bug 实际失效（又是从零），
  因此 v9/v10 本质是两次独立从零训练，结论等价。
- **关键机制（任务干扰）**：从零训练被避障奖励主导——策略学到"躲障碍"后，
  抓取信号（+100）被绕障惩罚（-90）抵消，梯度方向被避障锁住，抓取技能**长不出来**。
- **业界对应**：多任务/多目标 RL 的非平稳性 + 奖励冲突出现在同一网络优化中
  （对比：分层/分解架构将两目标解耦，见 §5）。

### v11：权重注入解锁感知 → 证明"感知锁死"是 warm-start 的根本障碍
- **探针**：归一化空间改 obstacle_rel 槽位——v6 输出 diff=0.00000（actor obstacle 输入权重 norm 0.178），
  **v6 的 actor 完全忽略障碍观测**；value 网络却感知（权重 norm 12.1）→"评估到风险但策略不管"。
- **权重注入**：只把 v6 actor 输入层 obstacle 槽位权重 0.178 → randn×0.1（norm 3.85），
  其余层保留 → v6_obsseed2 探针 diff 达 0.09~2.68（感知解锁）。
- **结果**：成功率 68-71.5% 保留（抓取不丢），但碰撞率 53-62%（v6 57-65.5% 几乎没降）。
- **双重结论**：
  1. **感知锁死是 warm-start 学不会避障的根因之一**（权重先验把障碍梯度压没）——可破解；
  2. **感知激活是必要不充分**——奖励经济学死结未解：穿障平均 -90 < 抓取 +120 → 理性选择仍是穿障。

### v12/v12b：碰撞即失败 → 探索空间压死，学习动力学崩
- penalty -20 + max_streak=1（碰一步即 terminated）：成功率 25%、碰撞率 71%（反而更高）、
  episode 均 25 步——策略"一碰就死"，无"碰→退→绕"试错路径。
- v12b（max_streak=3）：前 5 rollout 成功率平台 24-27%（与 v12 一致），更差。
- **决定性负结果**：碰撞终止把学习动力学搞死——**失败信号不能掐掉试错路径**。
  与 v9（从零无终止学出避障）对比：终止 vs 不终止是避障能否学出的关键变量之一。

## 3. 失败模式分类（四类独立机制）

| 类别 | 机制 | 涉及版本 | 可破解？ |
|---|---|---|---|
| **A. 无信号** | 无碰撞惩罚梯度 → 策略不感知 | v5 | ✅ 加惩罚 |
| **B. 奖励经济学** | 穿障负收益 < 成功正收益 → 穿障是理性解 | v6/v7/v8/v11 | ❌ 调参不可解（被 +120 成功奖励绑架） |
| **C. 感知锁死** | warm-start 权重先验压没障碍梯度 | v6→v11 全链 | ✅ 权重注入/从零（v9/v11 证明） |
| **D. 探索压死** | 碰撞终止让策略"一碰就死"，无试错路径 | v3/v12/v12b | ✅ 不终止 + 温和惩罚（v9 证明） |

**关键洞察**：B 与 D 是**结构性问题**——只要 RL 还承担"抓取+避障"双目标优化，
奖励经济学（B）就永远存在（成功 +120 绑架）；只要碰撞算失败，探索动力学（D）就被压死。
**两者共同指向同一结论：必须改变分工。**

## 4. 决策树：从失败证据到架构决策

```
"RL 同时学抓取+绕障"八版全败（§1-3）
    │
    ├─ 感知锁死（C）→ 权重注入/从零可解（v9/v11 实证）
    ├─ 奖励经济学（B）→ 调惩罚/终止均失败（v6/v7/v12/v12b 实证）
    │        ↓ 根源 = 成功奖励 +120 绑架了碰撞惩罚
    │        ↓ 只要"抓取"和"避障"在同一奖励里，穿障就划算
    └─ 探索压死（D）→ 终止必死（v12/v12b 实证）
    │        ↓ 根源 = 碰撞作为失败信号剥夺试错路径
    │
    ⇒ 结构性解 = 让 RL 不再承担"抓取"：
       抓取/静态避障 → MoveIt 标称轨迹（确定性规划，仿真替身 nominal_trajectory.py）
       RL 残差       → 只学"规划外"的动态修正（移动目标追踪 + 动态障碍避让）
       v_servo = v_nominal(t) + Δv
```

**新架构下四类失败如何消解**：
- **B 奖励经济学**：RL 不再为抓取奖励负责，只需"避开无惩罚、撞上受罚"——信号干净，死结解除。
- **D 探索压死**：动态避障是"追踪微调"（每步 2mm），不是大绕行；且明确禁止碰撞终止（§3.2）。
- **C 感知锁死**：动态场景里障碍是移动的，观测持续变化 → 天然有梯度（静态障碍才是 warm-start 锁死温床）。
- **A 无信号**：保留障碍接近惩罚梯度（obstacle_w）。

## 5. 与业界理论对应（面试谈资）

| 失败证据 | 理论对应 |
|---|---|
| v9/v10 从零：避障压过抓取 | 多目标 RL 奖励冲突出现在单网络优化中；分层/分解是标准解法 |
| v6-v11：穿障 -90 < 成功 +120 | 奖励稀疏/尺度失衡（reward shaping 不能根治结构性权衡） |
| v11 探针：actor 忽略障碍、value 感知 | 特征/注意力分配（网络容量被抓取占据）；warm-start 迁移中的先验固化 |
| v12：碰撞终止压死探索 | 失败信号设计（termination 剥夺 exploration，违反"试错学习"前提） |
| 新架构：标称 + 残差 | **Residual RL（Johannink et al. 2018, arXiv:1812.03201）**——残差适合小修正、不适合大偏离 |

## 6. 失败分析的方法论（简历可写"归因能力"）

1. **每版单变量**：只改一个配方因子（惩罚强度/终止阈值/障碍布局），保留其余 → 归因干净。
2. **探针实验**：修改观测槽位看策略输出 diff——区分"感知锁死"vs"奖励不足"。
3. **失败模式分类**：四类机制独立破解/证伪（§3）。
4. **学习动力学视角**：不只看最终指标，看 episode 长度/探索空间（v12 均 25 步是死因信号）。
5. **负结果也是结果**：v12b 提前终止（复现 v12 平台）+ 完整负证据链 → 路线级决策（换分工）。

**一句话总结**：八版失败不是调参问题，而是**"RL 同时优化抓取+绕障"在奖励经济学和探索动力学上的结构性问题**；
解法不是更强的惩罚或终止，而是**任务分解——MoveIt 管规划内（抓取/静态避障），RL 残差只学规划外（动态修正）**。
