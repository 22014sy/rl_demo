# P3 末端位姿控制与动作空间重构设计

日期：2026-08-20
状态：设计定稿 + 已实现（待重训验证）

## 一、背景与目标

P1/P2-2 之后，训练 200k 步仍学不会竖直朝下抓取（`diag_gripper_pose.py` 显示
`z_axis_z ≈ +0.06`、`success_rate = 0%`，见 `P2-2_相对接近姿态四元数观测.md`）。
复盘认为根因有三，本阶段（P3）针对其中两条结构性根因做重构：

1. **动作空间/控制接口过细且与“任务语义”错位**：RL 直接输出 7 维关节增量，把
   “把末端送到物体上方并对准”这个 6 自由度的任务压到关节空间里学，搜索空间大、
   样本效率低；且关节增量与末端运动之间隔着雅可比（方向反直觉），PPO 的随机策略
   很难稳定输出能同时到位+转向的动作。
2. **夹爪与抓取判定耦合在策略里**：肌腱（第 8 维动作）由策略直接控制，策略要么学
   不会“到位后闭合”，要么横夹/朝上骗奖励；成功判定又依赖 距离+夹紧+接触+朝下 的
   组合阈值，物理上脆弱、易被 hack。
3. **lift 原语属于另一个控制层级**：本阶段目标只是“RL 学会把末端送到物体并让夹爪
   合拢”，搬运/抬升是后续（控制器层）的事，不应混在 RL 动作/成功判定里。

### 本次重构目标

- RL 只控制**末端执行器位姿**（pose），不再直接控制关节或肌腱；
- 夹爪闭合改为**近距触发的自动动作**（环境内部状态机），RL 不再输出肌腱命令；
- **移除全部 lift 原语逻辑**（config 字段、environment.run_lift_primitive、脚本）；
- 成功定义改为**“手指被物体挡住合不上”**（开度仍 > `grasp_min_width` + 双指接触），
  替代旧的 距离+夹紧+接触+朝下 组合判定。

## 二、动作空间：关节空间 vs 末端笛卡尔空间

### 问题

旧动作空间（P1 起）：
`action ∈ R⁸ = [Δq1..Δq7, tendon]`，前 7 维是**每步关节增量**(±0.05 rad)，第 8 维肌腱。

关节空间增量控制的缺点：

| 维度 | 问题 |
| --- | --- |
| 维度/探索 | 7 维关节增量噪声大；随机策略在关节空间里的“有效移动”往往被雅可比/限位抵消 |
| 方向性 | 一个关节增量对末端的影响方向随位形变化（随动、随姿态），策略需学一个与位形相关的“映射”，而非直接学“往物体走” |
| 可迁移性 | 物体位置随机化（P0-2）后，关节空间策略几乎不可迁移；末端空间策略天然泛化 |
| 任务语义 | 任务目标本就是“末端到位+对准”，动作空间直接描述任务量纲，reward 与 action 对齐 |

末端笛卡尔空间增量控制的优点：

| 维度 | 说明 |
| --- | --- |
| 任务量纲 | 动作 = 末端在世界系的移动增量，策略输出与“去哪”直接对应，梯度信号最直接 |
| 低维 | 6 维（位置+姿态），探索压力远小于 7 维关节 + 肌腱 |
| 可迁移 | 末端空间与物体位置/臂架位形解耦，随机化场景下策略可复用 |
| IK 解耦 | 末端→关节由成熟的 DLS IK（`ik.solve_ik`）代劳，策略无需学关节协调 |

### 决策

**改为末端位姿增量（Cartesian delta）控制**：

```
action ∈ R^action_space_dim
  action_space_dim = 6 → [dx, dy, dz, dax, day, daz]
                        位置增量 (m) + 姿态增量 (rad，旋转向量)
  action_space_dim = 3 → [dx, dy, dz]  仅位置；姿态固定为“朝下接近”抓取姿态
```

- 每步位置增量限幅 `±max_ee_delta`（0.02 m），姿态增量限幅 `±max_orient_delta`（0.05 rad）；
- 姿态增量按**旋转向量叠加**到当前朝向：`dq = axis_angle_to_quat((dax,day,daz))`，
  `target_quat = dq ⊗ current_quat`（在手当前朝向上做小增量，无万向节死锁问题）；
- 目标位姿经 `ik.solve_ik` 反解为目标关节位形，写 `ctrl[:7]`（位置伺服）；
- IK 误差 > `ik_error_hold`（0.02 m）时**保持当前位置**（不朝不可达目标乱动）；
- `action_space_dim` 可配置：6 维全姿态是默认；若 6 维方向难训，可退化为 3 维
  （固定朝下姿态），先学会“到位+夹爪自动闭合”。

### 动作空间对比表

| 方案 | 维度 | 单位/量纲 | IK | 方向学习 | 迁移性 | 备注 |
| --- | --- | --- | --- | --- | --- | --- |
| 旧（P1）关节增量 + 肌腱 | 8 | rad + [0,1] | 无（直接写 ctrl） | 难（随位形变化） | 差 | 已废弃 |
| **P3 末端位姿增量** | **6** | m + rad | `ik.solve_ik` | 中等（欧拉增量叠加） | 好 | **默认** |
| P3 位置增量 + 固定姿态 | 3 | m | `ik.solve_ik` | 无（固定朝下） | 好 | `action_space_dim=3` 退化/对照 |

## 三、夹爪：近距自动闭合状态机

RL 不再输出肌腱命令。环境内部用带**滞回**的状态机驱动夹爪：

```
open ──(末端距物体 < gripper_close_distance)──▶ closing
closing ──(开度收敛且 > grasp_min_width 且双指接触)──▶ closed  ← 抓取成功
closing ──(开度收敛但 ≤ grasp_min_width / 超时)───────▶ open   ← 空闭合，重开重试
closed ──(开度滑脱 ≤ grasp_min_width 或失接触)────────▶ open   ← 失夹，重开重试
open ──(失败重开后的滞回：须离开到 > gripper_open_distance)──▶ 才允许再次闭合
```

- `gripper_close_distance = 0.12`：末端(hand 原点)→物体中心距离触发自动闭合；
- `grasp_min_width = 0.02`：**成功判定的核心**——闭合后手指开度仍 > 该值 = 手指被
  物体挡住合不上。实测校准：被 0.04m 物体挡住时开度(qpos 两指和) ≈ 0.029，空闭合 ≈ 0.007，0.02 居中取阈值（±8~9mm 余量）；
- `close_confirm_steps / close_width_tol`：开度收敛判定（连续 N 步 |Δwidth| < tol）；
- `gripper_open_distance = 0.18`：重开后的滞回距离，防止策略悬停在物体旁导致
  open↔closing 抖振；策略需先离开再重新接近才能再次闭合（可重试）。

## 四、成功判定：手指被物体挡住合不上

旧判定（P2-1）：`距离<0.11 ∧ 开度<0.05 ∧ 双指接触 ∧ z_axis_z≤−0.9`。
问题：多个阈值叠加、方向门控难训、容易横夹/侧夹。

新判定：**在 closing/closed 状态下，手指开度收敛后仍 > `grasp_min_width` 且左右双指
与物体有真实接触**。物理含义就是“手指试图闭合但被物体挡住合不上”——这正是“抓取”
的本质定义，不依赖距离/方向阈值，也不依赖 lift。

奖励结构不变（`reward.py` 的 距离势能塑形 + 方向项 + 接触 + `grasp_reward`/`completion_reward`），
但 `is_grasped == grasp_success == (phase == 'closed')`。

## 五、成本与影响

1. **旧模型作废**：`models/final_model.zip`（8 维动作、57 维观测）与新的 6 维动作 /
   58 维观测不兼容，**必须重训**；
2. **方向学习仍难**：6 维里姿态增量小（±0.05 rad/步），从任意初始朝向转到“朝下”需
   多步累积；若 6 维训不动，用 `action_space_dim=3` 固定朝下姿态退化训练；
3. **IK 每步实时求解**：`solve_ik` 默认 5000 次迭代在单步内成本可控（实测单次 < 几 ms），
   但训练步进变慢；迭代次数/容差可在调用处收紧；
4. **IK 失败回退**：目标不可达（误差 > `ik_error_hold`）时保持当前位置，避免乱动；
5. **观测维度 57 → 58**：追加 1 维夹爪状态机相位（open/closing/closed），
   让策略显式知道当前夹爪处于哪一阶段（对“何时停止/重试”有直接信息量）。
