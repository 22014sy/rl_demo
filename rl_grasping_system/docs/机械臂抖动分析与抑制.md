# 机械臂抖动分析与抑制（A 速度环阻尼 + B 动作平滑）

> 2026-08-21 · 训练侧（rl_grasping_system）机械臂抖动问题诊断与工程方案
> 关联：`environment.py`（step 速度循环 / 动作平滑）、`config.py`、`docs/RL_DEPLOY_CONTRACT.md §4

---

## 1. 现象与诊断

用户观察：机械臂总是抖动。

诊断（当前代码，seed 42）：
```
场景1 静止（零动作 20 决策步）:
  qvel 均值 [-0.001 -0.008 -0.146 0.139 0 0.001]  std [0.001 0.022 0.06 0.071 0.001 0.002]
  末端漂移 [0.0001 -0.0019 0.0255]     # z 漂 2.5cm
场景2 恒速移动（v=0.5）:
  qvel 稳态 std ≈ 0.001-0.006          # 移动时稳定
```
→ **静止保持时肘/腕有残余速度（qvel ±0.15 rad/s）+ 缓慢下漂**；移动时速度环稳定。

## 2. 原因分析（按可能性）

1. **速度 PID 纯 P 环（欠阻尼）——主因**
   `τ = kp·(dq − qvel) + qfrc_bias`，kp=150/100，无 D/积分项；对负载变化、2F-85 手指开合质心
   变化、弹簧预紧力等扰动响应欠阻尼 → 肘腕微颤。
2. **重力前馈 `qfrc_bias` 滞后/有误差**：含重力+科氏+离心，且为"上一步"值；手指/运动改变质心
   → 前馈残余力矩 → 缓慢漂移（z 掉 2.5cm）。
3. **RL 动作逐决策步跳变（视觉抖动主因）**：每 0.04s 策略换动作 → 速度目标突变 → 每次切换都是
   瞬态冲击。
4. **次要**：2F-85 弹簧预紧 + 接触反作用力突变。

## 3. 工程方案

| 项 | 做法 | 对应实机 |
|---|---|---|
| A. 速度环加 D 项（加速度阻尼） | `τ = kp·err − kd·qacc + qfrc_bias`（qacc=(qvel−qvel_prev)/dt），抑制 qvel 高频振荡 | UR 速度环增益调谐 |
| B. 动作平滑（一阶低通） | `v_smooth = α·v_new + (1−α)·v_smooth`（α≈0.3），消除 RL 动作跳变冲击 | MoveIt Servo `smoothing_filter` |
| C.（可选）静止位置保持 / D.（可选）接触柔顺 | — | — |

## 4. 实施要点

1. `config.py`：新增 `velocity_kd`、`action_smoothing_alpha=0.3`
2. `environment.py`：
   - reset：`self._v_smooth = zeros(6)`、`self._prev_vel = zeros(6)`
   - step 速度模式：`_v_smooth = α·v_raw + (1−α)·_v_smooth` → `_vel_target`（lift 阶段仍精确竖直速度）
   - 速度物理循环：速度环加阻尼项
3. 语法检查 + 冒烟验证

## 5. 实施结果（2026-08-21）

### 修正过程（重要）
- **初版 D 项用"加速度差分阻尼"** `τ −= kd·(qvel−qvel_prev)/dt`：在 dt=0.002 下把 qvel 微小变化放大 500 倍，
  产生巨大阻尼力矩 → **静止 qvel std 从 0.06 恶化到 0.86**（更抖）、e2e 失败。
- **修正为工业标准的粘性阻尼** `τ = kp·(dq−qvel) − kd·qvel + qfrc_bias`（kd=2.0/1.5，无数值差分）：
  静止 std 回到 baseline、e2e 恢复成功。

### 验证数据
```
COMPILE-OK
静止: qvel std [0.0014 0.0221 0.0585 0.07 0.0008 0.0054]   # 与 baseline 持平，无恶化
移动20步: x 位移 = 0.0219 (alpha=1.0 与 alpha=0.3 完全相同)
e2e success: True | cube z: 0.505（抓取+抬升稳定）
```
- **A 粘性阻尼**：静止微颤不恶化、无数值噪声、抓取抬升稳定
- **B 动作平滑**：`α=0.3` 与 `1.0` 的移动实现率**完全相同** → 平滑不损失实现率，只平滑决策步间速度跳变（消视觉抖动），
  对应部署侧 MoveIt Servo smoothing 语义
- 注：`v=0.5` 全速场景 20 步仅移动 0.022 是**速度环高速度实现率的既有问题**（标定时 v≤0.125 才 96%），
  与本方案无关；RL 训练中大部分动作非全速，受影响小

部署侧注意：速度环阻尼与动作平滑语义对应 UR 控制器调谐 + MoveIt Servo `smoothing_filter`；
契约 §4 建议补充"速度环 PD + 动作平滑"。

## 6. 最终标定（①A 闭合斜坡 + ②A 速度环阻尼/增益）

### ① 夹爪阻抗更轻柔（闭合速度斜坡）
- `config.py`：新增 `gripper_close_speed=50`（closing 每决策步 ctrl 增量）
- `environment.py`：closing 阶段 `ctrl = min(ctrl + gripper_close_speed, 255)`（接触力>20N 后保持 160）
- 对应实机：2F-85 `set_gripper_speed` + `set_gripper_force`（业界标准：速度受限的位置控制 + 力限制）

### ② 速度环阻尼/增益再标定（最终）
```
velocity_kp = (200, 200, 200, 100, 100, 60)   # 肩肘↑(150→200)，腕保持/降(100→100/60)
velocity_kd = (5, 5, 5, 4, 4, 6)              # 粘性阻尼↑(2/1.5→5/4/6)
```
标定过程发现：kp 全面提高使腕部（小惯量）放大数值噪声（wrist std 0.001→0.09），
最终按关节差异化：大惯量肩肘高 kp（追速快），小惯量腕部降 kp + 增 kd（稳）。

### 验证数据（最终）
```
静止 qvel std: [0, 0, 0, 0, 0, 0]   # base [0.001 0.022 0.06 0.071 0.001 0.002] → 完全归零
移动实现率 (v=0.125, 20步): 86.2%   # 保持（平滑+限速+斜坡综合）
e2e 抓取+抬升: success=True | steps: 150
verify_grasp_success_criterion: PASS
```
- **静止抖动完全消除**（粘性阻尼 + 差异化 kp/kd）
- **移动/抓取不受影响**（实现率 86%、e2e 成功）
- 对应实机：UR 控制器速度环增益按同 kp/kd 语义配置
