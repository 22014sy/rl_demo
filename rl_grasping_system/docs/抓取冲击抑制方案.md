# 抓取冲击抑制（"物体被弹飞"）方案讨论与实施记录

> 2026-08-21 · 训练侧（rl_grasping_system）抓取冲击/弹飞问题分析与工程方案
> 关联：`environment.py`（step / _update_gripper_control）、`config.py`、`docs/RL_DEPLOY_CONTRACT.md`

---

## 1. 现象与诊断

用户观察：机械臂抓得很用力，会把物体弹飞。

诊断（静止对准 + 手指闭合场景）：
```
pad 对准 cube，ctrl=255 全速闭合：
  phys5-29: cube 位移 [0,0,0]，width 0.092→0.070（渐进收敛）
cube 总位移（被弹）: [0,0,0] m
```
→ **"静止对准 + 闭合"本身不弹**（menagerie fingers 是 kp=100 位置伺服 + 弹簧阻尼，闭合渐进）。
**"弹飞"主要来自抓取动态过程**：策略高速接近（v 最高 0.5 m/s）时 pad/手指高速撞击 cube，
或"运动中闭合+下压"把物体推/弹出去。

## 2. 业界做法（三层）

### 2.1 夹爪：位置/力双模式（核心规范）
- 真实 Robotiq 2F-85：接近用位置控制（快、准），接触后**力控**（官方 `set_gripper_force(target_N)`，
  设置目标夹紧力如 40–80 N，内部 PID 到力，不硬压到底）
- 训练侧模拟同一语义：closing 阶段不是"无限压"，而是**接触力到达阈值后保持/限力**

### 2.2 末端：接近速度限制（approach speed limit）
- 工业标准（UR 手册）：抓取最后一段（距物体 < 5–10 cm）**限速 0.05–0.15 m/s**
- 训练侧：距物体 < 阈值时限制 `_vel_target` 位置分量模长

### 2.3 柔顺/接触处理
- 阻抗控制：接触后刚度/阻尼可调（部署侧 MoveIt Servo + 控制器）
- 柔性衬垫：2F-85 真实 silicone 衬垫缓冲（模型已有）
- 仿真接触参数柔顺化仅在数值反弹严重时使用，优先"物理上慢速+柔顺"

### 2.4 抓取后防甩脱
- 抬升用恒定低速（`lift_speed=0.003` 已满足）+ 抬升前验证抓稳

## 3. 推荐实施（训练侧，与部署语义一致）

| 项 | 做法 | 对应实机 |
|---|---|---|
| A. 接近限速 | 距 cube < `gripper_close_distance` 时，`_vel_target` 位置分量限幅（≤ `approach_speed_limit`） | UR 慢速 Servo 接近 |
| B. 限力闭合 | closing 阶段检测 pad-cube 接触力，超过 `grasp_force_limit` 后不再加压（保持中等压力） | 2F-85 `set_gripper_force` |
| C.（可选）闭合 ctrl 渐变 | closing 时手指目标逐步加压（menagerie 已部分天然具备） | 夹爪力控斜坡 |

部署侧（`ros2_moveit2_ur5e_grasp` D1 阶段）：2F-85 力控接口 + UR 接近限速 + MoveIt2 规划兜底；
契约 §8 补充"抓取力控制"条目。

## 4. 实施要点

1. `config.py`：新增 `approach_speed_limit=0.12`（m/s）、`grasp_force_limit=20.0`（N）
2. `environment.py`：
   - step 速度模式：`_vel_target` 设置后，若距 cube < `gripper_close_distance`，位置分量模长 > limit 则等比缩放
   - `_update_gripper_control`：closing/closed 阶段 `_get_grasp_contact_force() > grasp_force_limit` → ctrl 保持中等压力（不放 255 硬压）
3. 语法检查 + 冒烟验证（限速生效 + 限力后抬升仍稳）
4. 重启可视化训练验证"弹飞"消失

---

## 5. 实施结果（2026-08-21）

已完成并冒烟验证（e2e 固定目标 + 速度模式）：
```
COMPILE-OK
step30-140: phase=closed width=0.048 contactF=24.2 ctrl6=160 cube=0.354→0.501（稳定抬升）
final success: True
```
- **限力闭合生效**：接触力 24.2N > grasp_force_limit=20 → `ctrl6=160`（不再 255 全压），
  对应实机"接触后保持目标力"（2F-85 set_gripper_force 语义）
- **抓取+抬升不受影响**：width 0.048（手指被 cube 挡住）、cube 稳定抬升 0.354→0.501、success=True
- **接近限速**（A）已加：距 cube < 0.18 时 `_vel_target` 线速度模长限 ≤ 0.12 m/s
  （P 控制冒烟中动作小未显著触发，训练中随机大动作会被限幅）

部署侧注意：真实 2F-85 用官方力控接口（`set_gripper_force`）+ UR 慢速 Servo 接近 +
MoveIt2 规划兜底；契约 §8 建议补充"抓取力控制"条目。
