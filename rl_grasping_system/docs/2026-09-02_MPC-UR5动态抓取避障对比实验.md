# MPC-UR5 动态抓取避障对比实验（2026-09-02）

> 目的：为 v23 残差 RL 提供**最优控制（MPC）基线**，做三数对比
> （纯标称 / MPC / 残差 RL），验证「随机动态下精确模型失效、RL 靠经验学统计性规避」。

## 1. 研究假设（叙事判定线）

| 假设 | 判定 |
|---|---|
| H1 随机动态下**最优控制需精确模型**，模型失配即性能塌陷 | MPC dyn_both 成功率 ≤ 80%（v23 final 2障 80.0% 为参照） |
| H2 RL 残差策略靠**经验学统计性规避**（无需精确预测目标/障碍轨迹） | v23 dyn_target 83.3% / 2障 80.0%，且碰撞率低于 MPC |
| 边界：若 MPC ≥ 85%，则「精确模型失效」叙事不成立 | 结果不对外讲，不影响主叙事（主叙事 = RL 在模型失配下的鲁棒性） |

## 2. MPC 公式化（末端级，实时可解）

刻意放弃「关节级 + MuJoCo 前向预测」（MVP 过重、非线性非凸难实时），
采用**末端级**：预测只建末端单积分模型，避障用软约束，scipy SLSQP 每决策步重解。

```
决策变量   u ∈ R^{N×3}                未来 N 决策步末端速度
预测模型   p_{k+1} = p_k + u_k·dt      dt = 决策周期 0.04s（25Hz）
目标       hover_k = hover + target_vel·k·dt   动态目标速度外推
障碍       obs_k   = obs + obs_vel·k·dt        当前速度线性外推（随机游走下预测失效）
成本       Σ_k [ w_p‖p_k−hover_k‖² ] + w_o·Σ_k relu²(d_safe−‖p_col_k−obs_k‖)
           + w_s·Σ_k ‖u_k−u_{k−1}‖²
约束       |u| ≤ v_max = 0.125（契约速度，与 RL 同口径）
求解       scipy.optimize.minimize(SLSQP, x0=上步解 warm-start)；失败降级 P 控制
执行       action = v·T（env.step delta 模式），夹爪自动闭合状态机复用
```

超参数（冒烟标定，n=3：碰撞 33%→0%、成功 33%→67%）：

| 参数 | 值 | 说明 |
|---|---|---|
| N | 10 | 预测时域 0.4s |
| W_P | 40 | 到达 hover 权重 |
| W_O | 1500 | 障碍分离软约束权重 |
| D_SAFE | 0.20 m | 避障参考点→球心安全距离（球 r=0.05 + margin） |
| W_S | 2.0 | 控制平滑 |
| KP_P | 3.0 | P 控制兜底增益 |
| 避障参考点 | ee − 0.07·ẑ | 夹爪中部（覆盖 pad 端，比 ee 点碰撞早 0.134m） |

## 4. 三数对比（2026-09-02 实测，n=30 同口径）

| 控制器 | static | dyn_target | dyn_both(1 障) | 碰撞率(1障) | avg_len(1障) |
|---|---|---|---|---|---|
| 纯标称（历史消融） | 83.3% | 66.7% | **70.0%** | 20.0% | — |
| **MPC（本实验）** | **93.3%** | **80.0%** | **70.0%** | **0.0%** | 125.0 |
| RL 残差（历史消融 1 障） | 100% | 90.0% | **86.7%** | 23.3% | — |
| RL 残差 v23 final（本会话，1 障） | 96.7% | 83.3% | **86.7%** | **16.7%** | 94.7 |
| RL 残差 v23 final（本会话，2 障） | — | — | — | 36.7% | 109.1 |

- 纯标称/残差 1 障数据来自 `docs/一周冲刺方案.md`（三路消融，同 scenario 0,0,1 口径，n=30）；
  v23 为会话初三场景评估 + `results/v23_ckpt/`。MPC 为本次 `results/mpc/*_v2.json`。
- **同一场景（动态目标 + 1 动态障碍）三方：纯标称 70.0% = MPC 70.0% < RL 86.7%**。

### 4.1 结论（验收通过，H1/H2 成立）

- **MPC 70.0% ≤ 80% 验收线**：最优控制需精确模型，随机游走障碍的轨迹外推（`obs_k=obs+v·k·dt`）
  失效 → MPC 靠大裕度（D_SAFE=0.20）保守绕行，**碰撞 0% 但成功率塌陷**；纯标称在随机动态下同为 70%。
- **RL 靠经验学统计性规避**：1 障 86.7%（+16.7pp over MPC/标称）；v23 在更强的 2 障（80.0%、
  碰撞 36.7%）仍 ≥ MPC 1 障——**RL 用可控碰撞换更高的任务成功率**（两种避障哲学的最优权衡差异）。
- **碰撞率同口径（v23 本会话补测）**：v23 1障碰撞率 **16.7%**（5/30，其中 3 次仍成功），
  远低于 2障 36.7%，且 MPC 1障 0% 是牺牲 16.7pp 成功率换来的——「MPC 更安全」成立但
  「MPC 更好」不成立（见 §4.3 Pareto 权衡）。
- **可预测动态下 MPC 并不差**：static 93.3% / dyn_target 80.0%（目标三角波可预测 → 速度外推有效），
  均优于纯标称、接近 RL——差异只在「随机动态」暴露（H1 的精确边界）。

### 4.2 失败归因（dyn_both 9/30 失败，均 0 碰撞）

| 模式 | 计数 | 机制 |
|---|---|---|
| 到达超时（200 步） | 6 | 随机游走障碍堵路径 → MPC 大裕度绕行耗时；或接近末段目标换向反复追 |
| closing 未触发/重试 | 3 | 动态目标换向瞬间 pad 未对齐，closing 超时重开循环 |

## 5. 局限与边界（诚实声明）

1. MPC 是**末端级 + 单积分预测**，非完整关节级动力学 MPC；它代表「业界可实时部署的轻量最优控制」，
   不是学术全动力学 MPC 的上界。若用关节级 + 采样（MPPI）+ 真模型前向预测，随机动态下仍受
   「障碍轨迹不可预测」的根本限制——本基线已足够支撑 H1 的机制（模型失配）。
2. 目标动态是**三角波往返**（可预测），MPC 有速度外推优势；障碍是**随机游走**（不可预测），
   是 MPC 的硬伤点——这正是对比设计要暴露的差异。
3. n=30 单随机种子，误差 ±~8%；差异 >15pp 才视为结论性。
