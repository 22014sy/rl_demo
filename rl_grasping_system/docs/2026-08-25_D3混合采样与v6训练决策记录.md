# 2026-08-25 · D3 无障碍混合采样 + v6 训练决策记录

## 背景
- v5（D2 避障 warm-start 训练）实测（Step 0 评估 200 episodes/口径）：固定位置成功率 **74%**、随机 ±3cm **67.5%**，
  但**碰撞率 98%~99.5%**（平均 45~60 次碰撞/episode）——成功率已过 70% 线，**碰撞是 D3 验收红线**。
- 根因：v5 训练 `obstacle_collision_penalty=0`（无碰撞惩罚梯度），策略完全不顾碰撞、只求完成任务。
- 计划：加 30% 无障碍混合采样（§11.4）保抓取技能，warm-start v5→v6 冲 70% 成功率 + 0 碰撞。

## 决策 1：混合采样实现（per-episode 状态）
- 障碍全链路原依赖全局 `self.obstacle_enabled` → 引入 per-episode `_obstacle_active`，reset 按 `obstacle_mix_ratio` 采样。
- 隐藏 episode：contype=0 + 观测槽位 0 + `obstacle_dist=inf`（r_obstacle=0）+ 碰撞计数不触发。
- config 默认 `0.0`（不破坏 check_d1/check_d2）；D3 训练 CLI 传 `0.3`（30% 纯抓取 + 70% 绕障）。
- 验证：check_d2 场景 6（mix=1.0 隐藏 / 0.0 激活 / 0.5 实测 53% 激活）；check_d1 无回归。

## 决策 2：碰撞惩罚（达成"0 碰撞"验收线的必要信号）
- v5 无碰撞惩罚 → 98% 碰撞率。**无惩罚梯度则 0 碰撞不可达**，故 v6 必须引入碰撞信号。
- v3 教训：碰撞**终止**（`obstacle_collision_max_streak`）让"无障迁移 + 障碍难绕"早期探索死（episode 均 25 步）。
  但 v3 无混合采样保底、且用终止而非当步惩罚。
- 决策：**温和当步惩罚 `-2`/次**（非终止）+ 30% 无障碍保底。成功 +100 主导，-2/次 提供避碰梯度但不淹没抓取信号。

## 决策 3：CLI 哨兵 bug 教训（关键）
- `--collision-penalty` 合法值为**负数**；用 `>=0` 判"未指定"恒 False → **penalty 永不写入 config**
  （首轮 1517 episodes 的 r_collision 全 0，碰撞惩罚形同虚设）。
- 定位链：独立 env 碰撞检测/惩罚正常 → 训练 r_collision 全 0 且 r_obstacle 非 0（障碍激活但无惩罚）→
  检查 CLI 判断逻辑 → 改 `None` 哨兵（`is not None`）。
- 修复重启后**确认生效**：539 episodes 中 370 个有碰撞惩罚（≈69% = 70% 激活比）、avg r_collision **-76.8**、
  成功率 **72%**（未崩）。

## 决策 4（v6 完成）：成功率达标、碰撞减半但未到 0
- v6 评估（200/口径）：固定 **79.0%** / 随机 **75.5%**（成功率 ✅ ≥70%）；碰撞率 **65.5%/66.5%**（v5 98%→v6 65.5%）、
  平均碰撞 45→23 次。**0 碰撞未达**。
- 分析：63% 的**成功** episode 仍带碰撞（均 15 次）——`-2×15=-30` vs 成功 +100，**-2 惩罚太弱、碰着也划算**。

## 决策 5（v7 加强惩罚，❌ 未达标 → 决定不重复该路线）
- v7 = penalty **-5** + max_streak **30**（warm-start v6）：评估固定 69.5% / 随机 69%（**成功率掉到 70% 线下**）、
  碰撞率 64%/67%（≈v6）、平均碰撞 14/18 次（继续下降）。
- 结论：**max_streak 30 伤成功率、对碰撞率无益**；单纯加强惩罚把碰撞次数压到 14 但碰撞率卡 65% 不动。

## 决策 6（几何诊断 → 根因 = 障碍固定 → 无动态绕障）
- 证据 1：v5/v6/v7 残差幅度**恒定**（0.2164/0.2162，成功=失败）→ 策略不基于障碍观测改变动作（无动态绕障）。
- 证据 2：固定口径探针——障碍球面距 cube 中心 6~8.5cm（cube 半宽 ~2.5cm → **绕障间隙 3.5~6cm，几何可达 0 碰撞**）。
- 根因：障碍位置固定（fraction=0.5, lateral=0）→ 策略学"平均路径"直接穿障，惩罚只让它"碰一下快过"而非绕。
- 对策：**v8 障碍侧偏随机化**——每-episode lateral ∈ (-0.06, +0.06)，强制策略"看障碍在左绕左、在右绕右"。
  保留 penalty -5（压碰撞有效）、去 max_streak（伤成功率）、mix 0.3 保技能、warm-start v6。

## 决策 7（决定性探针：策略忽略障碍观测 → 0 碰撞不可达 → 交付 v6）
- v8 评估（200/口径）：固定 70.5%、障碍侧偏随机 73.0%（碰撞率 57% 首次 <60%）、随机物体+侧偏 65.5%。
- **探针**：直接改 obstacle_rel 槽位 [61:64]（真实/无/近/右/远 5 种）喂给模型——
  v6 **和** v8 输出**完全相同** [0.005,0.005,-0.005]（diff=0.00000）→ 策略输入层对障碍感知零权重，
  残差恒定是真实行为，不是评估统计掩盖。碰撞率降到 57% 是障碍偏出路径的统计效应。
- **结论**：4 轮训练（v5→v8）系统性证明——当前 residual PPO 配方下**策略无法学会基于障碍感知的动态绕障**；
  碰撞惩罚只能压碰撞次数（45→14~23），压不掉碰撞率（卡 53~67%）。0 碰撞需架构级改进（观测利用/奖励 shaping）。
- **交付**：**v6 = D3 正式产物**（成功率 79%/75.5% 最高且达标；碰撞 23 次/episode 较 v5 减半）。0 碰撞记录为已知限制，
  D6 真机评估容忍轻度擦碰或另行架构改进。

## 决策 8（v9 从零快速验证：打破"忽略障碍"权重先验）
- 背景：warm-start 锁定忽略障碍——v6 把 obstacle 输入权重学到≈0，v7/v8 继承该先验，PPO 在训练初期发现
  "障碍槽位对输出无影响"→ 梯度信号天然弱 → 永远学不会利用障碍。**这是 v5→v8 学不会避障的机制根源**。
- 对策：**从零训练（不带 --load-model）+ 障碍每-episode 侧偏随机 ±6cm + 硬避障（penalty -5）**——
  随机初始化让 obstacle 槽位一开始就随机影响输出，配合障碍随机化（obstacle 观测=预测障碍唯一线索），
  梯度有机会建立 obstacle→action 相关性。300k 步快速探路（低成本，~15 分钟 CPU）。
- 验证门（训练后立即做）：复用 /tmp/probe_model_obs.py 探针——改 obstacle_rel 槽位输出是否变化。
  变化 → 感知激活，评估后决定是否全量；不变 → 瓶颈在奖励/架构（碰撞太软 / residual 不适大偏离），
  D3 交付维持 v6，避障转 D6 真机后处理。
- 风险：从零放弃 v6 的 79% 起点，300k 步成功率必然偏低——但探路只看"感知是否激活"，不看成功率。

## 决策 9（v9 从零探路结果 → v10 续训）
- **v9 从零 300k 结果（假说成立 ✅）**：
  - 探针：改 obstacle_rel 槽位输出 diff=0.010/0.014（v6/v8=0.00000）→ **障碍感知激活**
  - 碰撞率：侧偏随机口径 **7.5%**（v6=57%）、固定口径 **22.5%**（v6=65.5%）→ RL 真学会避障
  - 成功率：0.5%/0.0%（从零 300k 只学完避障、没学完抓取；avg_final_distance 0.69~0.76m 够不到物体）
- **结论**：4 轮 warm-start（v5→v8）学不会避障的**根因 = warm-start 锁定"忽略障碍"权重先验**
  （v6 obstacle 输入权重≈0，后续全继承，PPO 无梯度激活障碍利用）。从零训练打破先验后，
  RL 在 300k 步内就学会利用障碍观测——**RL 能动态避障，之前是配方问题不是原理问题**。
- **行动 v10**：warm-start v9 续训 500k（保已激活的避障感知 + 补抓取技能）。训练分布同 v9
  （侧偏随机 ±6cm + penalty -5 + mix 0.3 + residual-reg 0.3 + obstacle-w 0.35）。
- 风险：v9 抓取基础差（训练平均 32%、评估 0.5%），v10 500k 若成功率仍 <70% → 续训更多步或调整
  mix（提高隐藏比例保抓取）/课程。评估 v10 用双口径（侧偏随机训练口径 + 固定）。

## 决策 10（v11 权重注入：感知解锁成功，奖励经济学未破解）
- **v11 = warm-start v6_obsseed2（actor obstacle 权重注入 randn×0.1）+ 障碍侧偏随机 ±6cm + penalty -5，
  500k 步**。
- 结果：成功率 **68%/71.5%**（固定/侧偏随机，v6 抓取保留，final_dist 0.156≈v6 0.153）、
  碰撞率 **53%/62%**（v6 57%/65.5%，几乎没降）。
- **结论**：
  1. 权重注入成功打破"忽略障碍"（v6 actor obstacle 权重 0.178→3.85，归一化空间改障碍槽位输出
     diff 达 2.68）→ 感知激活是可达的，且**不牺牲抓取**（此前 v8 从 v6 warm-start 失败是因没打破先验）。
  2. 但碰撞率不降 → **感知激活是必要不充分**；真正拦路的是"奖励经济学"：碰撞 -5/步太软，
     穿障平均 -90 < 抓取成功 +120 → 策略理性选择穿障。
  3. 对比 v9 从零（碰撞 7.5% 但抓取崩）：**要避障必须有强避障奖励主导，代价是抓取**；两者在
     当前奖励配方下不可兼得。
- **交付决策**：D3 维持 v6（成功率 79% 最优，0 碰撞为已知限制）；v11 保留为"成功率达标 + 感知已激活"
  中间产物，作为 v12（若做）起点。
- **v12 方向（未执行，待用户决策）**：v11 感知激活 + **碰撞惩罚 -20~-50 或碰撞终止**（使穿障不划算）
  + 障碍随机 + 课程（先固定障碍小惩罚保抓取，再强化避障），验证能否双达标。
