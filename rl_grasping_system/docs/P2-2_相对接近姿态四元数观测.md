# P2-2 相对接近姿态四元数观测（53 → 57 维）

日期：2026-08-20
状态：已实现，待重训验证

## 一、问题

P1/P2-1 之后，奖励已改为“手指朝下”方向项（`r_orient = w_orient·(−z_axis_z)`），
但训练后的策略在可视化中仍不总是竖直向下抓取。`diag_gripper_pose.py` 显示中间状态
夹爪水平/倾斜、`align` 不高。

**根因候选（本次针对观测信息量）**：观测中只有**绝对**四元数 `ee_orientation`（4 维）与
`target_orientation`（4 维，当前方块为 identity），策略需要自行做一次四元数除法
`q_target ⊗ q_ee⁻¹` 才能得到“手相对目标抓取姿态差了多少角度”的**相对**信号。方向任务
本就难学，让策略从原始四元数里合成相对转角，收敛慢、易被其他高方差维度淹没。

## 二、改动

### 1. `environment.py`
- 观测维度 **53 → 57**（末尾追加 4 维）。
- `_get_observation` 新增相对接近姿态四元数：

```python
# 目标抓取姿态 = 物体朝向(target_orientation) ⊗ 朝下接近旋转(Q_APPROACH_DOWN)
# （与 reward.py _orient_gain 同款约定）
q_target = ik.quat_mul(q_obj, Q_APPROACH_DOWN)
# 相对四元数：从当前手姿态转到目标抓取姿态的旋转（在手坐标系表达）
q_rel = ik.quat_mul(q_target, ik.quat_inv(q_ee))
# w≥0 规范化，消除四元数双覆盖歧义（q 与 −q 表示同一姿态）
if q_rel[0] < 0.0:
    q_rel = -q_rel
```

- 完全对齐时 `q_rel = [1,0,0,0]`（identity），可直接作为对齐误差信号。
- `obs_dim` 注释与模块 docstring 同步更新为 57 维。

### 2. `scripts/verify_p1_incremental_control.py`
- 回归断言 `obs_shape == 53` → `== 57`。

### 3. 文档
- 本文件（P2-2）记录改动与验证结果。

## 四、结果（2026-08-20 实测）

### 冒烟 + 全量重训
- [x] 冒烟通过：`scripts/smoke_train_p1.py 4096` → **SMOKE PASS**（57 维观测下 PPO 管线正常）。
- [x] 全量重训完成：200k 步（headless 临时脚本，glfw 后端，最新物理 ×10 臂 / ×7 夹爪），
     已更新 `models/final_model.zip`；669 episodes，mean reward **−0.95 → +9.63**（best +59.9）。

### diag_gripper_pose 验证：❌ 未达标
- 新模型 deterministic 推演：`z_axis_z ≈ +0.06`（手指**朝上**）、`align ≈ −0.98`、`r_orient < 0`、
  `grasp_success=False`。
- 训练监控：`success_rate = 0.0%`（669 episodes）。

**根因分析（三条并存的证据）：**
1. **策略未收敛**：PPO action `std` 200k 步内仅 1.0 → 0.965（动作空间仅 ±0.05，噪声仍主导，
   策略无法“承诺”动作）；`explained_variance ≈ 0.26`（critic 拟合差 → advantage 噪声大）。
2. **方向信号偏弱**：势能塑形望远镜式相消后，每步奖励量级极小（mean ≈ +0.03/step），方向翻转
   相对初始只是**一次性 ~±10** 的信号，被距离塑形淹没 → 策略学到“到位不转向”。
3. **评估路径观测归一化失配（历史遗留，见 P1 §5.6 TODO）**：`diag_gripper_pose`/`evaluate`
   把**未归一化**观测喂给以**归一化**观测（`norm_obs=True`）训练的 PPO；`VecNormalize` 统计
   未持久化，训练后无法恢复。训练侧 0% 成功率同样说明策略本身未学到竖直抓取（非纯评估失真）。

### 结论
- 观测加 `q_rel` 本身正确（57 维、单位四元数、w≥0 规范化），物理/IK/奖励回归**全绿**；
- 但**单靠该观测改动在 200k 步内未使策略学会竖直抓取**（策略未收敛 + 方向信号偏弱 + 评估失配）。
