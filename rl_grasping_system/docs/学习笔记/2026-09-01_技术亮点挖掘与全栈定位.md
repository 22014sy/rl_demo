## 二、5 个真技术细节（三层）

### 层 1：RL 学习动力学洞察（研究级，最稀缺）

**① 驻留陷阱（Ng 等价性）**
- 现象：策略停驻「够近但不精调」，成功率卡 0%
- 根因：shaping_gamma=0.9 < PPO γ=0.99 → 驻留每步白拿 (0.99−0.9)·Φ≈0.09·Φ，300 步≈31 ≫ 步惩罚 −15
- 修法：shaping_gamma → 0.99（=PPO γ），满足 Ng 势能塑形等价性
- 证据：DEV_LOG 2026-08-22、docs/奖励设计与混合塑形方案.md

**② 碰撞经济学 + 感知锁死双证伪**
- v6：-2×15=-30 < 成功+100 → 穿障是理性解（奖励设计问题非感知问题）
- v11 权重注入探针：actor obstacle 槽位权重 0.178→randn×0.1（norm 3.85）解锁感知；成功率保留、碰撞率不降 → 感知激活必要不充分，经济学死结不可调参解
- 证据：docs/2026-08-27_RL训练失败分析_v5到v12b.md

### 层 2：控制栈真实度（机器人背景面试官最看重）

**③ 速度级联执行层（复刻 UR 固件语义）**
- 链路：PPO 末端增量 → v=Δ/T → 速度IK(阻尼伪逆 λ=0.08) → dq → 速度PID+重力/惯性前馈 → τ
- 为什么速度模式：位置伺服小增量实现率 8-41% → 速度模式 96%
- 深度点：显式 M_eff·q̈_des + qfrc_bias 逆动力学前馈，复刻 UR speedJ（无前馈纯 P 环实现率仅 ~18%）
- 证据：environment.py:640-671、config.py:23-33、ik.py:38-65

**④ 观测/姿态表示严谨性**
- 相对接近姿态四元数 q_target_approach ⊗ q_ee⁻¹（58→67 维）
- 双覆盖：奖励 dot² 消除、观测 w≥0 规范化
- 区分表示层奇异（四元数解决）vs 运动学奇异（阻尼伪逆/可操作度观测/奇异检测）
- 证据：state.py:113/126、reward.py:56-62、docs/2026-08-31_控制架构与姿态表示设计问答.md

### 层 3：实验严谨性

**⑤ 消融 + 失败证据链 + 感知噪声鲁棒性**
- 端到端 vs 残差 vs 纯标称 × 3 场景 × n=30（run_ablation.sh 可复现）
- D6：感知噪声 σ≤0.03/漏检 20% 成功率无显著下降 → oracle 感知非瓶颈

### 全栈版 bullet（版本 D）

> ① 搭建 MuJoCo UR5e+Robotiq 动态抓取系统，端到端 PPO 8 版失败后归因出 4 类机制（奖励经济学/任务干扰/感知锁死/探索压死），以权重注入探针证明感知锁死可破而经济学死结不可调参解，据此设计「标称+残差」混合架构，三路消融（n=30）验证全场景最优（静态 100%/动态 90%/动态+障碍 86.7%）。
> ② 执行层自研「速度级联 + 逆动力学前馈」：阻尼伪逆速度 IK → 速度 PID + M_eff·q̈_des+qfrc_bias（复刻 UR speedJ），命令实现率 8%→96%，与 MoveIt Servo 语义同构，预埋 sim2real 契约。
> ③ 奖励塑形受 Ng 势能等价性约束（shaping γ=PPO γ）消除驻留陷阱；观测用相对接近四元数并处理双覆盖；D6 实验证明感知噪声 σ≤0.03/漏检 20% 下成功率无显著下降（感知非瓶颈）。
