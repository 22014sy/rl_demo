# 2026-09-01 · 消融 vs 鲁棒性：概念辨析（面试防踩坑）

> 起因：用户问「观测空间的消融是什么意思」。结论：项目里**没有**观测空间消融；D6 感知噪声实验是**鲁棒性/敏感性实验**而非消融。

---

## 1. 概念辨析表（面试必考）

| 维度 | 消融 Ablation | 鲁棒性/敏感性 Robustness/Sensitivity |
|---|---|---|
| 操作 | **移除/关闭**某组件 | **加噪声/扰动**让组件变差 |
| 目的 | 证明组件**必要、有贡献** | 证明系统对误差**有容忍度** |
| 判定 | 去掉后性能**显著下降**→组件有用 | 加噪后性能**保持不降**→系统鲁棒 |
| 一句话 | 删了看它多重要 | 弄脏了看它多抗造 |

## 2. 项目实际有的三类实验

| 项目实验 | 类别 | 内容 |
|---|---|---|
| 三路消融（端到端/残差/纯标称） | ✅ 真消融（方法/架构级） | ×3 场景 n=30，`run_ablation.sh` |
| D6 感知噪声实验 | ✅ 鲁棒性实验 | 只污染观测 target_position（σ≤0.03+漏检20%零阶保持），奖励/物理用真值→**感知-控制双通道隔离** |
| P2-2 观测设计（+4维 q_rel） | ⚠️ 设计决策，无 with/without 验证 | 观测含 q_rel/v_nominal/夹爪相位 |

## 3. D6 真实结论（别误读）

- 结论：**残差架构对感知误差天然鲁棒**（标称主导接近，≤3cm < grasp_align_xy_tol=0.030 时残差局部修正）
- 它证明的是「系统抗噪」，**不是**「某观测维度贡献大」
- 方法：感知-控制双通道隔离（`environment.py:_perceived_target_pos`，仅覆盖观测通道）
- 边界：未做鲁棒化训练（v18 是 oracle 训练的；v21_p3i_noise 是后续最小闭环）；只污染 RL 观测、标称仍用真值

## 4. 面试回答模板

**被问「做过观测消融吗」**：
> 「没有严格移除式消融，但做了三层验证：方法级三路消融、感知噪声鲁棒性（D6）、观测设计决策（P2-2）。其中 v11 权重注入探针已侧面证明『置零障碍观测→策略感知不到障碍』。」

**主动加分话术**：
> 「补正规观测消融我会做三组：① 移除 v_nominal→残差退化端到端；② 移除 q_rel→方向学习变慢；③ 置零障碍观测→学不会避障（v11 已有证据）。」

## 5. 观测设计可学性三实例（面试弹药）

| 观测设计 | 作用 | 出处 |
|---|---|---|
| 相对接近四元数 q_rel | 策略直读对齐误差，不自己合成转角 | P2-2（`environment.py:1437`） |
| 标称参考速度 v_nominal | 残差策略只学偏差的前提 | D1（残差三件套之一） |
| 夹爪相位/障碍相对位姿+速度 | 感知阶段与障碍才能学绕障 | P3/D1 |

> 一句话：**观测设计直接决定可学性与 sim2real**（信息够不够/显式给误差/泛化/部署一致性四维度）。
