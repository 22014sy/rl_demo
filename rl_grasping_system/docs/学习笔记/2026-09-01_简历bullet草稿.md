## 版本 A：完整四段式（项目描述 / 自我介绍用）

### ① 项目背景
基于 MuJoCo 仿真搭建 **UR5e + Robotiq 2F-85** 机械臂「到达-抓取」系统，任务为抓取**动态移动**物体并**规避动态障碍**，面向具身智能强化学习（RL）的 sim2real 部署。

### ② 我的工作
- 独立搭建 RL 抓取全链路：MuJoCo 环境（观测/动作/奖励/场景随机化）、PPO 训练、评估、监控、云端无头训练
- 对端到端 PPO（抓取+避障联合）完成 8 版迭代，系统性归因出**四类失败机制**，论证失败是「任务分解」问题而非调参问题
- 设计并实现**混合残差架构** v_servo = v_nominal(t) + Δv（MoveIt 标称轨迹 + PPO 残差），完成三路消融实验验证其必要性

### ③ 困难与解决方法
- **难点 1**：端到端 PPO 同时学「抓取+避障」8 版全败——要么抓不到（成功率<5%）、要么完全不顾碰撞（碰撞率>90%）
  → 失败归因四类机制（无信号 / 奖励经济学 / 任务干扰 / 感知锁死+探索压死）→ 将任务**分解**为「标称规划（静态避障）+ RL 残差（动态修正）」，让 RL 只学规划外偏差
- **难点 2**：位置伺服滞后，小增量命令实现率仅 8%-41%，RL 早期随机动作推不动末端（训练 0% 的根因之一）
  → 执行层改造为**速度模式**（阻尼伪逆速度 IK + 速度 PID + 重力/惯性前馈，复刻 UR speedJ 语义），脉冲实现率提升至 **96%**

### ④ 量化结果
- 三路消融 × 3 场景 × n=30：**残差架构 静态 100% / 动态目标 90% / 动态+障碍 86.7%，全场景最优**
- 对比端到端（26.7% / 63.3% / 43.3%）全场景大幅领先；对比纯标称（83.3% / 66.7% / 70%）在动态场景优势显著
- 结论：**标称解决静态、残差解决动态、端到端均不如残差**；残差对域变化最鲁棒（静态域扩大后仍 100%，契合 sim2real）
