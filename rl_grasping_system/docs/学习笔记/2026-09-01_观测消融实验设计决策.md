## 2. 为什么只消融 v_nominal

- 67 维观测中候选：v_nominal(6) / q_rel(4) / obstacle_rel+vel(6) / manipulability(1) / grasp_phase(1)
- **v_nominal 是唯一「消融结果直接检验核心命题」的变量**：残差立论 =「RL 只学偏差，因策略看得到标称意图」
- 消融 v_nominal（train-time）= 策略看不到标称意图，但标称仍物理带它走 → 预期：**静态不掉、动态显著降**
- 代码：`environment.py:1494`（v_nominal 槽位）、`:552`（v=v_nominal+Δv/T）

## 4. ⚠️ 方法论纪律：必须 train-time

- eval-time 置零 = 敏感性测试（与 D6 同类），**不是消融**（训练有信息/评估拿走，不公平）
- train-time 移除 = 真消融，回答「该信息对学习是否必要」
- **只能选 train-time → 需要重训**

## 5. 成本与可行性
