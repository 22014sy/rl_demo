## 0. 全景：一条数据流 + 文件索引

一个 RL 决策步长这样（都发生在 `environment.py` 的 `step()` 里）：

```
action [dx,dy,dz]              ← PPO 输出（末端位置增量，3 维）
   │  速度级 IK（雅可比阻尼伪逆, ik.py）
   ↓
关节速度目标 → 速度 PID + 重力前馈（环境内执行层）→ mujoco 物理步 × action_repeat(2)
   ↓
MuJoCo data（qpos/qvel/xpos/site…）
   ↓
state.py: get_proprioceptive_state() 读本体状态字典
   ↓
environment._get_observation()  拼 67 维观测向量
reward_breakdown()              算 11 个奖励分项 → calculate_reward 求和
_is_done()                      判 terminated/truncated
   ↓
返回 (obs, reward, done, info)
```

| 环节 | 文件 | 关键函数/行 |
|---|---|---|
| 环境 | `environment.py` | `GraspingEnv` L30；`_setup_spaces` L320；`reset` L346；`step` L522；`_update_gripper_state` L1253；`_get_observation` L1426；`_is_done` L1542 |
| 状态读取 | `state.py` | `get_proprioceptive_state` L74 |
| 奖励 | `reward.py` | `reward_breakdown`(~L135)；`calculate_reward` L247；`REWARD_KEYS` L70 |
| 参数 | `config.py` | `GraspingConfig` L10 / `RewardConfig` L317 / `TrainingConfig` L284 |
| 评测 | `evaluate.py` | `run_episode` L61；`evaluate_model`(~L118) |
| 判据验证 | `scripts/verify_grasp_success_criterion.py` | 三场景 |
| 奖励分项可视化 | `scripts/plot_reward_breakdown.py` | |

**理解整个项目的钥匙 = 任务分解**：RL 只干极小一件事——"把末端走到哪"（3 维位置增量）；
夹爪闭合、抬升、标称轨迹全是环境里的结构化状态机 / 标称层。这让 RL 的可学信号极干净，
也让"失败归因"可分层（物理/执行层、奖励层、训练层）。

## 1. 环境（environment.py）

### 1.1 reset：每局从"可复现"开始

`reset(seed)`（L346 起）做的事：
1. `super().reset(seed)` 拿环境 RNG → **整局所有随机都由 seed 决定**（`_sample_object_position` 用 `self.np_random`）
   ——"固定 seed + n=30 评估可复现"的地基（P0-2）。
2. `singularity_handler.generate_safe_initial_config` 生成围绕 home 小范围随机的初始位形（避开奇异与桌面插穿）。
3. 夹爪全开、`ctrl=0`（menagerie 2F-85：0=张开）。
4. 物体位置采样：`use_fixed_position=True` 固定 (0.5,0)；`False` 在 `workspace_bounds` 里随机。
5. **场景采样**（`scenario_mix`）：每局按概率抽"静态 / 动态目标 / 动态+障碍"三档之一
   ——三路消融数字（100/90/86.7）的来源，一局只测一种难度。
6. `prev_state = 初态`：**P1.3 关键**——势能塑形 `Φ(s_prev)−γΦ(s)` 需要前一步，初始就置成初态，
   首步也按势能差算 → 望远镜式相消、累计有界。
7. 障碍沿标称路径放置，每局 `obstacle_path_lateral` 随机——**逼策略"看障碍观测动态绕障"**
   （v5/v6/v7 碰撞率卡 65% 根因：障碍固定、策略学"平均路径"直接穿障）。

### 1.2 step：三个子系统

- **执行层（velocity 模式）**：动作增量 → 速度级 IK（雅可比阻尼伪逆 `(JᵀJ+λ²I)⁻¹Jᵀv`，λ=0.08 兼奇异降速）
  → 关节速度目标 → 环境内"速度 PID + 重力前馈"用 motor 力矩执行。
  为什么不用旧位置伺服：**实测小增量实现率仅 8%（伺服过阻尼追不完）→ 速度模式 96%**——"训练 0% 成功"案例的执行层根因。
- **夹爪状态机**（`_update_gripper_state` L1253）：`open → closing → closed`。
  触发闭合不是"距离"而是**对齐判定**：物体中心与夹爪中心（左右 pad 中点）XY<3cm、Z<3.2cm 才闭合——防侧方误触发。
- **成功判定**：closing 里开度收敛（连续 `close_confirm_steps=3` 步 `dw≤4mm`）后，
  **`width > grasp_min_width(0.02) 且双指接触` → closed**。"手指被物体挡住合不上 = 成功"；
  空闭合（开度收敛到≈0）→ 重开重试，带滞回（须离开到 `gripper_open_distance` 外才允许再闭合，防抖振）。
- **抬升（P4）**：成功后环境自动抬物体 0.2m（`lift_enabled`，默认关；RL 不参与，max_steps 只计抬升前步数）。
- **提前终止**：掉桌（物体 z < 桌面顶−5mm → 失败）、奇异连续 50 步（truncated）、
  碰撞连续超阈值（`obstacle_collision_max_streak`，默认 0=关——**碰撞=失败默认不启用**，
  因 v3 实证会让 episode 平均 25 步、探索即死）。

> **面试一句话**：环境 = "物理真（MuJoCo 官方 UR5e/2F-85 模型）+ 执行真（速度级 IK+速度环，实现率 96%）
> + 判定严（对齐触发 + 挡住合不上才是成功）"。

## 2. 观测（state.py → `_get_observation`，67 维）

### 2.1 67 维结构（`_get_observation` 拼接顺序，`obs_dim` 注释在 config L18）

| 段 | 维度 | 为什么 |
|---|---|---|
| 关节位置/速度/力矩 | 6+6+6 | PPO 学"动力学"的最低信息 |
| 夹爪开度/速度/张力 | 1+1+1 | 状态机反馈 |
| 末端位置/四元数/速度 | 3+4+6 | 动作直接作用层 |
| 夹爪状态 | 1 | 冗余槽位 |
| 目标位置/朝向 | 3+4 | 任务目标 |
| 可操作度/接触力/双指力 | 1+1+3+3 | 奇异/接触感知 |
| **相对接近姿态四元数 q_rel** | 4 | **显式对齐误差** |
| 夹爪相位 | 1 | 告知策略"我在哪个阶段" |
| **标称参考速度 v_nominal** | 6 | 残差策略关键输入 |
| **障碍相对位姿 + 速度** | 3+3 | 动态避障关键输入 |

合计 67 = `18+3+3+14+1+7+2+6+4+1+6+3+3`。

### 2.2 四个设计原则

1. **显式给相对量，不让策略合成**（P2-2）：观测本有绝对四元数 `ee_orientation` + `target_orientation`，
   但策略要自己算 `q_target ⊗ q_ee⁻¹` 才知道"差多少角度"，方向任务难学。改成直接喂
   `q_rel = q_target ⊗ q_ee⁻¹`（w≥0 规范化消除四元数双覆盖），完全对齐时 `q_rel=[1,0,0,0]`。
   结论：**该由环境算好的、策略合成不了的量，环境算好再喂**。
2. **残差槽位第一天就位**（D1）：`v_nominal`(6)、障碍 rel/vel(3+3) 在观测空间定型那天就留好
   ——观测空间"第一天即最终形态"，后面加场景不加维度。delta 模式 `v_nominal` 占位 0，residual 模式喂真值。
3. **感知-控制双通道隔离**（D6）：观测通道的 `target_position` 可加高斯噪声/漏检（`_perceived_target_pos`），
   但**奖励和物理位置永远读真值**——量化"控制层鲁棒性"vs"感知层鲁棒性"可分开；
   也是简历"±3cm 噪声/20% 漏检成功率不降"的口径依据。
4. **归一化交给 VecNormalize**：观测空间是无界 Box，由 SB3 `VecNormalize` 归一化（`normalize_observations=True`）。
   **坑**：评估必须加载训练时保存的 stats（`vec_normalize_wrapper.py`）——P2-2 踩过"评估喂未归一化观测
   给归一化训练的模型 → 结果失真"。

> **面试一句话**：观测设计原则 = "本体感知为主 + 显式给对齐误差 + 残差/障碍槽位第一天就位 + 感知控制通道隔离"。

## 3. 奖励设计（reward.py —— 最有含金量、面试最可能深挖）

### 3.1 总公式（`reward_breakdown` + `calculate_reward`）

```
r = Φ(s_prev) − γ·Φ(s)                    # 势能塑形：距离(xy/z) + 近距离锚定 + 朝向
  + w_contact·[接触] + close_trigger + grasp_reward   # 事件奖励（上升沿一次性）
  − step_penalty                            # 时间惩罚
  − obstacle_w·(1−d/range)                  # 障碍接近惩罚（连续）
  − residual_reg·‖Δv‖²                      # 残差幅度正则
  + obstacle_clear_bonus·[成功且0碰撞]        # v16 奖励经济学
```

`REWARD_KEYS`（L70）只对这 11 个键求和；`orient_align/z_axis_z/potential` 等**诊断键在 `diag` dict，绝不进奖励**
——修"方向项修了却不见效"的关键：曾用 `sum(values())` 把诊断键（`z_axis_z` 手指朝上+1/朝下−1 = **反向信号**）以系数 1 注入奖励。

### 3.2 三类奖励的"为什么"

**① 势能塑形（距离/朝向）**——核心是 `r = Φ(s_prev) − γ·Φ(s)`：
- 为什么不是"距离绝对值当负奖励"：绝对值每步固定负值会**累计膨胀**——P1.3 前 300 步累计 −800、成功 +16 被淹没。
  势能差是**差分**，telescoping 塌缩成端点差 → **累计有界**，且满足 **Ng et al. 1999 势能塑形等价性**（不改变最优策略）。
- `Φ_xy = w_xy·min(d,cap)/scale + anchor_w·min(d/anchor_dist,1)`：主势能 + **近距离锚定**。
  为什么锚定：主势能近距离每步收益 ≈0.03 < step_penalty 0.05 → 策略"停在够近但不精调"（悬停陷阱）。
  锚定让近距离斜率 ×3.5，每靠近一步收益 0.115 > 0.05 → 精调到最后一步有利可图。
  **必须单调**（d=0 处 Φ=0）；曾误用 `max(0,1−d/d_target)` 使近距离非单调（靠近反被惩罚）。
- **驻留陷阱（γ 匹配）**：`γ_shape=0.9 < γ_mdp=0.99` 时，策略停驻每步白拿 `(γ_mdp−γ_shape)·Φ ≈ 0.09·Φ`
  正收益 → "停在中途最优"。`γ_shape=0.99` 后停驻收益=0，塑形只提供梯度、行为由事件奖励驱动。
- 方向项演进（P2-1）：`max(0,cosθ)` 在夹角 >90° 时**死区无梯度** → 改为 `w_orient·(−z_axis_z)`
  （手指朝下投影，全程连续有梯度，不惩罚绕手指轴 roll）。当前 `action_space_dim=3`（姿态固定朝下）→ `w_orient=0`
  （姿态无自由度，方向项纯损耗，每 episode 白扣 ~6 分）。

**② 事件奖励（稀疏、大额、上升沿一次性）**：
- `w_contact=5`（接触即奖）、`close_trigger_reward=5`（进入 closing = 中间里程碑）、`grasp_reward=100`（is_grasped）。
- 为什么加中间里程碑（方案②）：只有 grasp_reward=100 太稀疏，策略停在"pad 触发区边缘 4cm"（PPO_93 分析：4/10 未进 closing）。
- **上升沿一次性**（`grasp_success_rising`）：成功当步才发，避免每步重复领取；抬升阶段（`lift_active`）事件/塑形/步罚全冻结。

**③ 惩罚 = 经济学表达**（D2/v16）：
- `r_obstacle = −obstacle_w·max(0, 1−d/range)`：接近连续惩罚，梯度引导远离。
- `r_residual = −residual_reg·‖Δv‖²`：L2 鼓励小残差——**静态场景 Δv≈0、动态才出手**（对应"残差幅度统计：静态小/动态大"分工）。
- `obstacle_clear_bonus`（v16 奖励经济学）：成功当步若全程 0 碰撞 → +bonus。
  为什么：v15 时"穿障成功"仍净赚（碰撞 −5×10=−50 < 成功 +120），**穿障是理性解、惩罚强度调不回来**（v7/v19 实证）；
  bonus 让"绕障成功(+100+30) 严格优于 穿障成功(+100)"→ 主动绕障。默认 0 保持旧行为。

### 3.3 演进史 = 面试的"诊断叙事"

绝对值 −800 淹没成功 → 势能塑形（有界+策略不变性）→ γ 匹配消驻留陷阱 → 近距离锚定修悬停 →
无死区方向项 → 事件中间里程碑 → 奖励经济学 → 诊断键隔离。每一步都有 `docs/*.md` + 数值证据
（`P1_奖励与收敛修复.md`、`奖励设计与混合塑形方案.md`、`调参失败分析.md`）。

## 4. 评测（evaluate.py + 判据验证 + 协议）

### 4.1 评测流水线

`evaluate_model` 跑 n 个 episode，每局 `agent.predict(deterministic=True)`——**确定性动作**，
把"策略能力"和"策略方差"分开看（`run_episode` L61）。统计：
- `success_rate`（主指标）
- `avg_reward / avg_episode_length / avg_final_distance`
- `collision_rate` + `avg_collision_count`（避障质量）
- `avg_residual_norm_success/fail`——**成功=小残差、失败=大残差**，验证"残差只补偏差"分工

### 4.2 判据验证（最该记住的教训）

`scripts/verify_grasp_success_criterion.py` 是**"成功判定本身必须被验证"的门禁脚本**，三场景：
- A 正确抓取：摆到位 → 自动闭合 → 开度 > 阈值 + 接触 → `grasp_success=True`；
- B 空闭合：摆到侧方 0.06m（够触发距离但手指够不到）→ 不闭合、不误判成功；
- C 重试滞回：空闭合后离开物体 → `retry_hold` 清除可重试。

退出码 0=通过。**P0（唯一剩余任务）** = 把这套标准迁移到 peg-in-hole：对齐容差收敛到物理容差 1mm +
插到位/无擦壁/无穿板验证——因旧判定 5mm 容差 vs 1mm 物理容差，**擦壁/穿板会判成成功**
（简历已撤数字、改写"验证意识"故事）。

### 4.3 数字口径（简历三个数的可信度来源）

静态 100% / 动态 90% / 动态+障碍 86.7%（n=30）成立的前提，必须能说清：
- **确定性评估**（deterministic）；
- **n=30 固定 seed**：每局 `reset(seed)` 由 RNG 决定物体/障碍/初始位形 → 固定 seed 序列 = 同一批局，
  不同模型可比、可复现（P0-2 已固化）；
- **场景分层**：`scenario_mix=(0.4,0.3,0.3)` 每局抽一档，数字按档统计——三个数各有口径，
  不是混在一起的平均数；
- **每个改动过回归**：env/reward 改动必须跑 `scripts/verify_*.py` + `check_d1.py`，判据再过
  `verify_grasp_success_criterion.py`。

> **评测哲学一句话**："评估指标必须自己验证"——数字不是跑出来的，是
> "判据验证 + 确定性 + 固定 seed + 分层口径"四条腿撑起来的。

## 5. 把四段串起来：一个闭环诊断案例

奖励/评测不孤立，失败诊断恰好横跨全部四段（简历文档 §11.6 四步定位法）：

**案例：训练 0% 成功 → 分层取证**
1. 先验物理/执行层：`verify_ee_pose_control.py` → 小增量 Δz=0.003 **实际实现率仅 8%**（伺服过阻尼追不完）
   → 根因在**执行层**（环境那一段），不在奖励；
2. 修复：速度级 IK + `action_repeat=2` → 实现率 8%→96%，训练从 0 开始收敛；
3. 若执行层正常才查奖励/训练层：`plot_reward_breakdown.py` 看单步分项 → 发现"近距离塑形斜率 < 步罚"（悬停）
   → 加锚定势能；
4. 归因后区分"可调参修复 vs 结构性问题"：8 版端到端失败（奖励经济学 + 探索动力学在单网络双目标下不可解）
   → **路线级决策换残差架构**，而不是继续调参。

这个案例就是"环境→观测→奖励→评测"四段各管什么的活教材：
- 环境决定"动作到物理可达吗"（实现率）；
- 观测决定"策略能读到信息吗"（感知锁死/槽位缺失）；
- 奖励决定"梯度指向对吗"（塑形斜率/经济学）；
- 评测决定"数字可信吗"（判据验证 + 口径）。
