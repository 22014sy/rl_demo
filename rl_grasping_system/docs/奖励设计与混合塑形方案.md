# 奖励设计：绝对值 vs 势能塑形 vs 混合锚定方案

> 2026-08-22 · A 训练（UR5e 40k 步）成功率 0% 的奖励侧根因分析与修复
> 关联：`reward.py`、`config.py`、`docs/DEV_LOG.md`、`docs/VecNormalize观测归一化替换.md`

## 1. 背景与根因

A 训练（139ep / 40k 步，官方 VecNormalize 下）：
- `rdist_xy` 累计 49.2→53.5、`rdist_z` 47.2→80.0（势能塑形**增量**，高 = 靠近过程多）
- `r_contact`=0、`r_grasp`=0（从未触发抓取）、成功率 0%

对照昨晚 panda 成功日志（221532）：成功 episode 塑形增量≈0（策略停在目标不动）+ `r_grasp`=100
→ **A 训练策略"大幅靠近但未精确对准"**（闭合触发需 pad 与 cube 中心 XY<3cm / Z<2cm）

### 根因（补充：驻留陷阱）
1. `w_contact=0`、`w_orient=0`（2026-08-22 调试时被禁用，git diff 确认）→ 接触/方向无学习信号
2. **驻留陷阱（关键机制）**：`shaping_gamma=0.9 < PPO γ=0.99` → 策略停驻时每步白拿
   `(γ_mdp−γ_shape)·Φ ≈ 0.09·Φ` 正收益（d≈0.05 处 ≈0.105/步，300 步 ≈31 ≫ 步惩罚 −15）。
   **策略停在"够近但不精调"的位置反而是最优驻留**（驻留收益最大区域）。
   数学上势能差总回报 = Φ(s₀)−γᵀΦ(s_T) 只在 γ_shape=γ_mdp 时严格塌缩；γ_shape<γ_mdp 时
   中间驻留项 (γ_mdp−γ_shape)·Φ 残留在单步回报里，函数近似下被策略学到并利用。
3. 唯一事件奖励 `grasp_reward=100` 需走完"对齐→闭合→width 收敛"全链路，40k 步探索概率≈0

## 2. 讨论：为什么不用"距离绝对值归一化"当负奖励（结论记录）

- 项目的势能 `Φ = w·min(d,cap)/scale` **本身就是"归一化距离绝对值"**（单步有界、梯度恒定）
- **直接用 −Φ**：单步有界但**累计膨胀**——卡住不动每步扣 `Φ`，300 步 = −N·Φ 吞掉成功奖励
  （P1.3 历史实测：300 步累计 −800，成功 +16 被淹没）
- **归一化只限"单步幅度"，限不了"累计"**：只要每步固定负值，长 episode 必然累积
- 塑形 = Φ 的**差分** `Φ(s_prev)−γ·Φ(s)`：telescoping 塌缩成端点差 → **累计有界** + **策略不变性**
  （Ng et al. 1999，势能差不改变最优策略；绝对值是路径依赖、有偏差）
- 塑形的弱点：① 目标附近增量→0（最后一步失信号）；② 中间驻留每步 `(1−γ)Φ`（拉策略停在中途）
- **正确解法：保持势能差形式（有界+不变性），在近距离叠加更陡的锚定势能**（专治最后一步）

## 3. 混合方案（已实施）

在现有主势能上叠加**近距离锚定势能**（单调分段线性，保持势能差形式）：

```
Φ_xy = w_xy·min(d_xy,cap)/xy_scale + anchor_w_xy·min(d_xy/anchor_dist_xy, 1)
Φ_z  = w_height·min(dz,cap)/height_scale + anchor_w_z·min(dz/anchor_dist_z, 1)
r_dist = Φ(s_prev) − γ·Φ(s)     # 仍是势能差：有界、不改最优策略
```

| 参数 | 值 | 效果 |
|---|---|---|
| `anchor_w_xy` / `anchor_dist_xy` | 1.0 / 0.06 m | d<6cm 时 xy 梯度斜率 6.7→**23.3**（×3.5） |
| `anchor_w_z` / `anchor_dist_z` | 1.0 / 0.04 m | d<4cm 时 z 梯度斜率 20→**45**（×2.25） |
| `w_contact`（恢复） | 5.0 | 接触即奖励，压紧动力 |
| `w_orient`（恢复） | 3.0 | 手指朝下顶抓信号 |
| `shaping_gamma`（修正） | 0.9 → **0.99** | = PPO γ，消除驻留陷阱（停驻收益 0），满足 Ng 等价性 |

性质：
- **单调**（d=0 处 Φ 最小，靠近总得正奖励）——⚠️ 曾误用 `max(0,1−d/d_target)` 导致近距离非单调（靠近反被惩罚），已修正
- **驻留陷阱已消除**：γ_shape=γ_mdp=0.99 → 停驻每步塑形收益=0，塑形只提供梯度方向，行为由事件奖励（接触/抓取）驱动
- 远距离梯度不变（常数偏移 `anchor_w` 均匀驻留，无策略偏差）
- 近距离斜率变陡 2-3.5 倍：每靠近一步塑形收益 γ·slope·Δd ≈ **0.115 > step_penalty(0.05)**，精调最后一步有利可图（主塑形 0.033 < 0.05，这正是必须加锚定的原因）
- 累计仍有界（势能差 telescoping）
