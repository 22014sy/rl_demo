# 2026-08-28 · peg-in-hole 最小尝试（接触操作信号可行性验证）

> 目的：4 周计划 Week 2 的最小前置验证——搭建最小可运行的 peg-in-hole 环境，
> 用极短训练（60k 步）验证"对准 → 插入"接触操作信号可学（成功率从 0 上升）。
> 结果：**成功率 0% → 100%**，信号可学 ✅，peg-in-hole 作为第二个简历卖点路线成立。

---

## 1. 设计（最小尝试范围）

| 项 | 方案 | 说明 |
|---|---|---|
| 场景 | `models/universal_robots_ur5e/ur5e_peg_hole.xml` | 复用 UR5e+2F-85+桌面；`target_cube`→`hole_board`（200×200×20mm，14×14mm 方孔，4 段 box 围成）；移除障碍 |
| peg | 固定连 `rq_base_mount`（局部 +z 0.13，tip +0.05） | **跳过"抓 peg"环节**，聚焦接触插入；夹爪保持张开 |
| 动作 | 3D 位置增量（max 5mm/步），速度级 IK 执行 | 复用抓取环境执行语义（λ=0.08、速度 PID+前馈） |
| 观测 | 21 维：关节位置/速度(12) + peg 尖端位置/速度(6) + 孔中心(3) | 最小观测 |
| 初始位形 | IK 把 peg 尖端放孔正上方 6~10cm + 水平 ±2cm | 课程式先易后难 |
| 奖励 | 水平对准势能 + 垂直接近 + 插入深度线性奖励 + 成功(+100) + 步罚 | 一旦插入即有正收益 |
| 成功判定 | peg 尖端插入深度 ≥ 12mm（孔深 20mm） | 物理判据 |

## 2. 关键调试（面试可讲）

1. **IK 初始位形 bug**：`mj_resetData` 后 qpos=0（臂下垂近奇异），DLS 从奇异出发落局部极小
   （实测 tip 水平偏 12cm、高度错位）→ **修复：先置 SAFE_CONFIG 再 IK**。
2. **peg 挂错层级**：peg body 插在 `rq_base_mount` 之外，偏移异常 → 修正到正确层级。
3. **单位误读（自查）**：`insertion×100` 是厘米被误当毫米，导致"成功率与深度矛盾"假象
   ——数据本身完全合理（成功 = 插入 ≥12mm）。

## 3. 结果（PPO 8 env，60k 步，n=30 确定性评估）

| 阶段 | 成功率 | 平均插入深度 |
|---|---|---|
| 训练前（随机策略） | 0% | −33mm（孔面上方 3.3cm）|
| 训练后 | **100%** | **+15mm**（低于孔面 15mm，> 12mm 阈值）|

- **插入信号可学**：60k 步（CPU ~10 分钟）从 0% 到 100%，"对准 → 下降 → 插入"奖励梯度有效。
- 训练后 episode 仅 13~22 步即成功（远小于 200 步上限）——策略学会直接下插而非漫游。

## 4. 意义与局限

**意义**：
- 接触操作（peg-in-hole）是 RL 操作方向核心技能，本最小尝试证明**信号可学、收敛快**，
  4 周计划 Week 2-3 路线可行；
- 与抓取（残差架构）互补，简历第二个 bullet："接触插入 + 阻抗基线对比"。

**局限（最小尝试的诚实边界）**：
- peg 固定连末端（未学"抓 peg"）；孔固定（未做随机/扰动）；无阻抗基线对比；
  无姿态随机/摩擦扰动鲁棒性验证——均为 Week 2-3 后续工作。
