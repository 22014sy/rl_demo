## PPO_90 · 惩罚调整后完整训练（200k 步，12 环境并行）

- **时间/日志**：2026-08-22 22:37 → 22:46（`training_log_20260822_223723.json`，1104 episodes）
- **配置**：3D 动作空间、spread 0.15、max_steps 200、惩罚调整（w_orient=0.0、step_penalty=0.05）

### 奖励分别为
| 指标 | 值 | 解读 |
|---|---|---|
| 平均奖励 | **+2.78**（单调上升 0.37→5.47） | ✅ 惩罚调整生效，奖励转正 |
| 成功率 | 0.00% | 仍无成功 |
| r_step | -10.00 | 步惩罚减半生效 |
| r_orient | +0.00 | 方向纯损耗消除 |
| r_dist_xy / r_dist_z | +5.84 / +5.99 | 靠近在学 |
| r_contact | +0.96（后期接触率 50%） | 接触翻倍 |
| r_grasp | 0.00 | 闭合从未触发 |

### 观察到的问题（进展 + 卡点）
- **突破**：模型评估 60 episodes，**73% 进入 closing 相位**（pad 到达触发区），接触时 24/28 满足触发条件
  ——策略已学会"到达抓取位"。
- **卡点**：closing→closed 0/60。实验实录（closing 期间逐帧）：
  ```
  closing+0: width=0.090 XY=0.041 Z=0.002 接触力=0.0   ← pad 在 cube 上方但没夹到
  closing+1: width=0.083 ... 动作=[0.005,-0.005,0.005] ← 策略还在移动 pad！
  ...
  closing+7: width=0.017 接触力=0.0                     ← 8 步内宽度 0.09→0.013
  closing+8: phase=open  width=0.013                    ← 空闭合回退
  ```
- **根因**：
  1. `grasp_align_xy_tol=0.045` 太宽松：pad 距 cube 中心 4.5cm 时 pad 在 cube 表面**外 2.5cm**
     （cube 半宽 2cm），手指合拢夹不到。
  2. closing 阶段**策略不停手**（持续输出动作 pad 一直动）+ 手指快速合拢
     （宽度变化 ~0.01/步 > close_width_tol 0.004）→ "连续 3 步宽度收敛"判定永不满足
     → 宽度降到 <grasp_min_width 0.02 → 判空闭合回退。

### 超参数分别是
- `action_space_dim=3`、`max_steps=200`、`spread=0.15`
- `w_orient=0.0`、`step_penalty=0.05`（惩罚调整，已生效）
- `w_height=8.0`、`anchor_w_z=2.0`、`anchor_dist_z=0.06`（方案A，Z 下压已生效）
- `grasp_align_xy_tol=0.045`、`grasp_align_z_tol=0.032`（← 问题项 A）
- `close_confirm_steps=3`、`close_width_tol=0.004`、`max_close_steps=60`（闭合判定）
- `ent_coef=0.005`、`n_steps=2048`、`n_epochs=10`、`num_envs=12`、`lr=2e-4`

### 目前处理方法（已实施 A+B）
| 方案 | 改动 |
|---|---|
| **A** | `grasp_align_xy_tol` 0.045 → **0.030**：pad 必须几乎正对 cube 中心才触发 closing（手指能夹住） |
| **B** | `environment.py`：closing 阶段覆盖 RL 动作（`_vel_target=0`，类似 lift 阶段），pad 停住让手指自然合拢 |

### 预期
A 保证"对准了才闭合"、B 保证"闭合时 pad 不动" → 打通 closing→closed 最后一环，首次出现真实成功。

## PPO_89 · 方案A后完整训练（200k 步，12 环境并行）

- **时间/日志**：2026-08-22 21:56 → 22:04（`training_log_20260822_215542.json`，1104 episodes）
- **配置**：3D 动作空间、spread 0.15、max_steps 200、方案A奖励（w_height=8.0、anchor_w_z=2.0、anchor_dist_z=0.06）

### 奖励分别为
| 指标 | 值 | 解读 |
|---|---|---|
| 平均奖励 | **-13.80**（Q1=-17.0, Q2=-14.8, Q3=-11.0, max=37.4, min=-24.8） | 仍为负 |
| 成功率 | **0.00%**（0/1104） | 无成功 |
| r_step | **-20.00** | ⚠️ 固定：200步 × step_penalty 0.1 |
| r_orient | **-5.99** | ⚠️ 纯损耗：3D 固定姿态下方向项恒 -0.03/步 |
| r_dist_xy | +5.73 | XY 靠近在学 |
| r_dist_z | **+5.98**（上轮 3.9） | ✅ 方案A 生效，Z 下压学好了 |
| r_contact | +0.48 | 接触率 ~9.6%，无提升 |
| r_grasp / r_success | 0.00 | 闭合从未触发 |

### 观察到的问题：**惩罚太重**
1. `step_penalty=0.1` → 每 episode **固定 -20**（200 步），吞掉策略全部靠近收益（XY+Z ≈ +11.7）。
2. `w_orient=3.0` 在 3D 固定姿态下是**纯损耗 -6/episode**——姿态不可变，方向项恒为 -0.03/步，
   无学习信号却白扣分（上轮为 6D 恢复 w_orient 3.0，但当前跑 3D 应关闭）。
→ 平均奖励 -13.8，事件奖励（grasp=100、contact=5）占比被严重稀释。

### 超参数分别是
- `action_space_dim=3`、`max_steps=200`、`spread=0.15`
- `step_penalty=0.1`、`w_orient=3.0`（← 问题项）
- `w_height=8.0`、`anchor_w_z=2.0`、`anchor_dist_z=0.06`（方案A，Z 下压已生效）
- `ent_coef=0.005`、`n_steps=2048`、`n_epochs=10`、`num_envs=12`、`lr=2e-4`

### 目前处理方法（已实施）
| 项 | 前 | 后 | 理由 |
|---|---|---|---|
| `w_orient` | 3.0 | **0.0** | 3D 固定姿态下方向项是纯损耗，关闭（6D 时恢复 3.0） |
| `step_penalty` | 0.1 | **0.05** | 200 步成本 -20→-10；方案A 下压收益 0.17-0.33 仍 >> 0.05，不受影响 |

预期：平均奖励 -13.8 → 约 -3~+2，学习信号更清晰。

### 遗留
Z 下压已解决，**卡点转移到"接触对齐"**（r_contact 仅 0.48，接触了也未闭合）。
若重训后仍不成功，下一步动闭合触发难度或 XY 对齐奖励，而非继续调惩罚。

## PPO32 · 早期 Panda 训练（奖励上升但 value_loss 震荡 / entropy 反升）

- **时间**：2026-08-19 前后（早期 Panda 模型，原始记录见 `docs/调参失败总结`）。
- **现象**：reward 上升、len 下降（机械臂在学靠近），但 value_loss 震荡上升、entropy_loss 从 -11 到 -12。
- **根因**：`ent_coef=0.2` 太大——优化器发现"动作乱抖（熵↑）就能让总损失降更低"，优先满足熵奖励，
  机械臂在靠近目标时手指颤抖，无法精确对准和抓取闭合；value 网络学习率追不上奖励突变导致震荡。
- **处理**：`ent_coef` 0.2 → **0.005**（砍 40 倍）；`vf_coef` 0.5 → **0.25**。
- **预期**：entropy 转头向下（策略变自信）、value_loss 震荡但不创新高、reward 持续上扬。
