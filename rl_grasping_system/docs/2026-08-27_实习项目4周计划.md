# 实习项目 4 周冲刺计划（混合架构抓取 → 接触操作 peg-in-hole）

> 定位：投**具身智能 RL 实习**的简历项目。纯仿真（MuJoCo），**不做真机**；
> 真机留到**毕设**（本计划已埋 sim2real 接口）。
> 起点：P2 已完成（两段 nominal 标称替身 90%、`docs/2026-08-27_部署分工与最小验证.md` §8）。
> 配套：失败分析方法论见 `docs/2026-08-27_RL训练失败分析_v5到v12b.md`。

---

## 1. 项目卖点（简历 3 条 bullet 的目标形态）

1. **混合架构动态抓取**：UR5e+Robotiq 仿真，"MoveIt 两段标称轨迹 + PPO 残差修正"，
   静态抓取 ≥90%、动态目标 ≥60%。
2. **接触操作**：peg-in-hole 残差 RL，接触修正相对阻抗控制基线成功率提升，±5mm/±3°/摩擦扰动下鲁棒。
3. **方法论**：8 版端到端 RL（抓取+避障联合）失败归因（4 类机制）→ 设计残差分解架构 → 消融验证其必要性。

---

## 2. 分工架构（贯穿全项目）

```
v_servo = v_nominal(t) + Δv
  标称（MoveIt 仿真替身 nominal_trajectory.py）：
     抓取接近 + 静态避障（规划内，确定性）
   RL 残差（PPO，67 维观测，12 env × 25Hz）：
     只学规划外修正——动态目标追踪 / 动态障碍避让 / 接触精对准
```

## 3. 四周里程碑

### Week 1：动态抓取闭环（P3）——出基础指标
> 状态：**完成（2026-08-27）**。三连训练 v13→v15：最终 v15_p3c 评估 **3/4 达标**
> （静态 96.7%、动态 0.03 91.7%、动态 0.05 83.3%）；动态+障碍碰撞率 80% 为 trade-off 残余。
> 详细结果见 `docs/2026-08-27_部署分工与最小验证.md` §9。

| 任务 | 验收 |
|---|---|
| 训练分布 40% 静态无障 / 30% 动态目标 / 30% 动态目标+动态障碍（per-episode 场景采样） | ✅ 分布采样正确（200 reset：38.5/30/31.5） |
| warm-start v11 + 两段 nominal 重新训练（v13→v15 三连，各 500k） | ✅ v15 最终成功率 86%（训练）/ 静态 96.7%（评估） |
| 评估矩阵：静态 / 动态 0.03/0.05 / 动态+障碍 × closing | **静态 96.7% ✅、动态 0.03 91.7% ✅、动态 0.05 83.3% ✅、动态+障碍 90%/碰撞80% ⚠️** |
- 代码落点：`environment.py`（scenario_mix 采样）、`train_with_monitor.py`/`evaluate.py`（CLI + --target-vel）✅

### Week 1 复盘（失败→修复链，简历素材）
1. **残差恒定 0.216 ≈ √3×v_max（饱和）**：v11 残差为单段标称学的，warm-start 到两段标称反而干扰
   → residual_reg 0.5→1.5 压到 0（静态 80%→96.7%）
2. **动态障碍布局错**：fixed_pos 在 robot 侧不扫路径 + on-path 分支 obstacle_vel bug（被钉住）
   → on-path 动态障碍 + bugfix
3. **双动态避障 trade-off**：obstacle_w 2 + collision -5 + 样本 50% → 碰撞 93%→80%，成功率 90%

### Week 2：peg-in-hole 环境 + 阻抗基线（区分度核心）
| 任务 | 验收 |
|---|---|
| MuJoCo 装配件（孔 12mm × 柱 10mm，2mm 间隙起步）+ 目标位姿随机 | 环境可 reset/step |
| 标称两段轨迹送末端到孔正上方（复用 nominal，调 clearance） | 纯标称能到位 |
| **阻抗控制基线**：对准→垂直下压+力控，测成功率 | **基线数字出炉（对比锚点）** |
| 奖励：接近（复用）+ 接触力引导 + 插入深度里程碑 + 到位 | 可学 |
- 应急：接触参数调参耗时 → 间隙放宽（5mm）、参数抄论文默认

### Week 3：残差 RL 训练 + 鲁棒性验证
| 任务 | 验收 |
|---|---|
| 残差 RL（接触力观测已有）；课程：先静态对准→再接触插入 | 成功率收敛 |
| 评估：成功率 vs 阻抗基线 | **残差 RL ≥ 基线** |
| **鲁棒性**：位置扰动 ±5mm、姿态 ±3°、摩擦 μ∈[0.3,0.9] | **RL 在扰动下优势明显（核心卖点）** |
- 应急：接触训练不稳 → 奖励 shaping 迭代、间隙放宽

## 5. 风险与对策

| 风险 | 对策 |
|---|---|
| P3 动态达不到 60% | 部分成果（静态 90% + 混合架构）已够简历；降级为"动态部分提升" |
| peg-in-hole 训练不收敛 | 课程化（先对准后插入）、2mm→5mm 间隙、力引导奖励迭代 |
| 消融时间不够 | 砍到单对比"残差 vs 端到端" |
| 面试问真机 | 话术：仿真阶段 + 架构为真机部署设计，毕设阶段做 sim2real |
