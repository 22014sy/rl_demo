# 绕行路点对照（seed 12345 逐集配对，max_steps=200，T=0.04 s → 8.0 s 上限）

四臂：纯 MPC / MPC+绕行路点 / MPC+RL / MPC+绕行路点+RL。MPC 各臂一律开 `--arm-aware`。

**读表纪律**：① 头条指标是**成功避障率**（无碰撞且抓起成功）；「达成最小余量」是**关节插值代理路径**上的精确表面距，不是执行轨迹实测值，且**不作为达标判据**（1 cm 目标已于 2026-09-20 取消）——只用来回答「绕行层绕开了多少」。② 碰撞数只计**窄相接触**，MuJoCo 窄相会漏掉深穿透 mesh-sphere 对，故碰撞率**偏宽**；各臂同计数器，横向可比，绝对值须带此保留。③ 同一场景两档 `d_safe` 的结论**不可互相外推**。
