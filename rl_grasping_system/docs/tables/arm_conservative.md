# 臂身保守度扫描：成功避障率 vs `arm_margin`

场景 `mixed3, mixed_z`，`d_safe ∈ {0.05}`，每臂 `--arm-aware`，seed 12345 逐集配对，`max_steps=200`（T=0.04 s → 8.0 s 上限）。

**头条 = 成功避障率（无碰撞且抓起成功）**。1 cm 余量目标已于 2026-09-20 取消，本表不报任何「离目标差多少」的量。n=30 的 95% CI 宽约 ±15pp —— **不要把 3–4pp 的差异读成结论**。碰撞数只计窄相接触，绝对值**偏宽**（各臂同计数器，横向可比）。
