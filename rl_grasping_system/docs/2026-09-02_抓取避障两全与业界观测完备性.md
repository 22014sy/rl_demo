## 1. 先归因：v23 静态 96.7% 是什么失败

`results/v23_mix/static.json` 30 集仅 1 失败（episode #10）：

| 字段 | 值 | 含义 |
|---|---|---|
| episode_length | 200 | 满步**超时**（非碰撞/掉桌/奇异） |
| collision_count | 0 | 无碰撞（静态场景本就无障） |
| grasp_success | false | 未完成闭合→抬升链 |
| final_distance | 0.164 | pad 停在 hover 位附近（成功集 ~0.145-0.156）但没抓上 |

**结论**：静态无障失败 = "到达+闭合链"超时，**与避障无关**。v22/v18 静态均 100%，
96.7% = 29/30，差 1 个超时 → **mix 切换瞬态 × n=30 小样本噪声**，非架构缺陷。

## 2. "抓取避障两全"方法清单（按性价比分档）

> 前提：单 PPO 网络同时承担"精对准抓取"与"绕障避障"，冲突根源在此。
> 硬结论：调碰撞经济学已到 Pareto 前沿（v18 penalty-10/w3/bonus+30 最优，v19/v20 证伪再调），
> 进一步必须换维度。

### A. 零训练成本档（优先）
1. **Multi-checkpoint 择优**（本记录 §5）：训练每 ~4 分钟存 checkpoint，逐个评估静态+2障，
   挑"静态 100% ∧ 2障 ≥80%"的 Pareto 最优——不调架构/奖励/不重训，纯评估筛选。
2. 静态复测 n=60：确认 96.7% 是否真实（可能仅 1/30 噪声）。

### B. 训练档（30-60 分钟/版）
3. 同 mix 续训 300-600k：v23 掉静态更像 mix 切换瞬态，同分布续训让策略稳定。
4. 静态锚定：静态样本残差趋零（标称独立可抓 90%+），residual_reg 强化防避障训练扰动抓取链。

### C. 维度/架构档（真正的"两全"，半天级）
5. **观测完备化**：k 近邻障碍（67→73 维）或势场压缩向量。当前 2 障只看最近 1 个 = 信息不完备。
6. **分层**：静态/可预测障碍交回 MoveIt 规划 + 安全层（CBF），RL 只留动态反应修正 + 抓取微调。

## 3. 业界视角：分层是主流，"全观测"是单策略路线的内部修正

### 3.1 业界主流 = 控制分层（三层），不是 RL 全观测

| 层 | 业界标准实现 | 负责 |
|---|---|---|
| 规划层 | MoveIt OMPL / RRT / 静态 costmap | 静态/可预测障碍绕障（确定性、可证明无碰撞） |
| 安全层 | CBF / DWA / 局部规划器 / 速度限幅（ISO/TS 15066 SSM） | 未预见障碍反应式兜底、急停 |
| 执行/微调层 | Servo + RL 残差 / PID | 轨迹跟踪、动态目标修正、抓取微调 |

> 本项目 ROADMAP 与 `混合控制架构设计.md` 早按此设计（静态归 MoveIt、动态归 RL、安全层 §6 未实现）；
> 训练链路 `obstacle_on_path` 逼 RL 连静态绕障也学，是**单仓库纯 RL 演示的自选难度**，非业界常规。

### 3.2 观测充分性原理：不是"全上帝视角"，是"决策变量完备"

- 避障决策需要：每个相关障碍的 rel 位置 + 速度（多少个就多少个，或最近 k 个）；
- 抓取决策需要：目标 rel + 速度、末端自车状态、夹爪接触/开度。
- 当前 67 维只给**最近 1 个障碍** → 2 障时第 2 个对策略不可见，靠"贴障绕行训练手感"硬扛 = 碰撞率天花板。

### 3.3 观测完备化的两种正规做法

1. **k 近邻障碍**：k = 场景障碍上限（本项目 max 2-3），每个 +6 维（rel+vel）→ 67→73 维；
2. **势场/栅格压缩**（Nav2/costmap 惯例）：不管几个障碍，压缩成"障碍到末端最近距离 + 方向场"固定向量——
   固定维度但包含"哪个方向最挤"，信息比"只看最近一个"完备。

### 3.4 单策略全包的业界标配（若坚持这条线）

观测完备化 + 课程/防遗忘回放（PER）+ 辅助奖励分层（避障成功独立 bonus，已用 clear_bonus）+
更长训练。但业界普遍认知：**硬学多技能不是无限加样本能解决的，加样本不如改信息结构或拆层**。

### A1 执行中的坑（2026-09-02 17:15 发现并修复）

**现象**：checkpoint 评估首次全 0%（30/30 超时），而 warm-start 策略不应如此。

**根因**：`agent.py:327` pkl 路径拼接 `splitext(model_path)[0] + "_vecnormalize.pkl"`——
对 checkpoint `..._mix_98304_steps.zip` 找 `..._mix_98304_steps_vecnormalize.pkl`，
但 SB3 CheckpointCallback 实际存 `..._mix_vecnormalize_98304_steps.pkl`（`_vecnormalize` 在 `_steps` **前**）→
找不到 → 跳过 obs_rms 恢复 → 观测归一化失配 → 策略乱走 0%。final 模型无 `_steps` 后缀不受影响。

**修复**：`models/` 下为每个 checkpoint 建 symlink（`<base>_steps_vecnormalize.pkl` → `<base>_vecnormalize_<steps>_steps.pkl`）。
修复后评估恢复正常（静态场景 100%）。

**教训**：multi-checkpoint 择优必须先做「归一化一致性校验」（任一 checkpoint 静态抽 3 集成功率应 ~100%），
否则 pkl 失配会伪装成「早期 checkpoint 很差」。

### 结论

1. **无 checkpoint 达「静态 100% ∧ 2障 ≥80%」**：v23 系列静态 93.3-96.7% 波动（各 1-2 个到达超时失败），
   2障随训练单调升 63→80%。**final 300k 即联合最优**——multi-checkpoint 择优在此案例未提供额外增益。
2. 静态失败全为「到达超时」（200 步、无碰撞、无奇异），与避障无关；v22/v18 静态 100% →
   差异 = mix 切换后 v23 对少数难初始位形（spread 0.15）的接近策略略降，或 n=30 噪声。
3. **「抓取避障两全」答案**：v23 final（静态 96.7 / 动态目标 83.3 / 2障 80）已是当前 mix 系列的
   联合 Pareto 最优——两全的下一步不在 checkpoint 选择，而在训练分布（§2-B）或观测/分层（§2-C）。
4. 若要静态回 100%：初始位形 spread 0.15→0.10（静态超时直接消减，动态影响小）或静态复测 n=60；
   若要 2障再升：B3 同 mix 续训 600k 或 C5 观测 67→73。

## 8. MPC 基线三数对比（2026-09-02 完成，scripts/mpc_ur5_grasp.py，results/mpc/*_v2.json）

**目的**：给 v23 提供最优控制（MPC）基线，验证「随机动态下精确模型失效、RL 靠经验学统计性规避」。

**控制器**（末端级滚动最优控制，SLSQP，N=10，dt=0.04s，v_max=0.125 契约）：
决策变量=未来 N 步末端速度；预测 p_{k+1}=p_k+u_k·dt；目标/障碍按当前速度外推；
成本=到达 hover + 障碍分离软约束（D_SAFE=0.20、W_O=1500）+ 终端硬权重 + 平滑；
**两阶段接近**（XY 未对准时目标 z 抬高 0.06，对准后才降）防 pad 侧撞推走 cube。
执行与 RL 同 env.step（delta 增量），夹爪状态机复用，closing/lift 自动接管。

**n=30 同口径结果**：

| 控制器 | static | dyn_target | dyn_both(1 障) | 碰撞率(1障) | avg_len(1障) |
|---|---|---|---|---|---|
| 纯标称（历史消融） | 83.3% | 66.7% | **70.0%** | 20.0% | — |
| **MPC（本实验）** | **93.3%** | **80.0%** | **70.0%** | **0.0%** | 125.0 |
| RL 残差（历史消融 1 障） | 100% | 90.0% | **86.7%** | 23.3% | — |
| RL 残差 v23 final（本会话，1 障） | 96.7% | 83.3% | **86.7%** | **16.7%** | 94.7 |
| RL 残差 v23 final（本会话，2 障） | — | — | — | 36.7% | 109.1 |

**结论（叙事验证通过）**：
1. **同一场景三方：纯标称 70% = MPC 70% < RL 86.7%（+16.7pp）**。随机游走障碍下 MPC 的
   轨迹外推失效 → 大裕度保守绕行，碰撞 0% 但成功率塌陷到与简单启发式（标称）打平；
   RL 用可控碰撞换更高成功率（v23 1障碰撞 16.7% / 2障 36.7% 仍 86.7%/80% 成功）。
2. **可预测动态下 MPC 不差**：static 93.3% / dyn_target 80%（目标三角波可预测，速度外推有效），
   均优于纯标称、接近 RL——H1 的精确边界 = 「随机动态」。
3. **MPC 碰撞 0% vs RL 1障 16.7%（v23 同版本同口径）/ 2障 36.7%**：两种避障哲学的
   最优权衡差异（保守绕行 vs 经验规避）的量化证据。MPC 的 0% 不是「更优」，而是
   「安全优先」的极限——牺牲 16.7pp 成功率换零碰撞，与 v19 强惩罚 RL 保守瘫痪同源（见 §8.1）。
4. **诊断复盘（值得写进简历的调试）**：MPC 曾 static 仅 10%——诊断发现「直线斜向逼近时 pad
   XY 未对准即降至 cube 高度，侧壁推着 cube 桌面滑动，closing 永不对齐」→ 两阶段接近修复
   后 10%→93.3%（+ dyn_target 66.7→80、dyn_both 53.3→70）。

**边界**：MPC 为末端级单积分预测（非完整关节级动力学 MPC），代表「业界可实时部署的轻量最优控制」；
关节级 + 采样（MPPI）+ 真模型前向预测在随机障碍下仍受「轨迹不可预测」的根本限制，不改变 H1 结论。
