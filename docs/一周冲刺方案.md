# 一周冲刺方案（简历项目：混合架构动态抓取避障）

> 创建：2026-08-24 · 决策记录，供新会话/新窗口无缝接手执行。
> 关联：`docs/混合控制架构设计.md`（三层架构）、`docs/ROADMAP.md`、`rl_grasping_system/docs/CHANGELOG.md`。

## 1. 背景与约束

- 目标：强化学习运动控制实习简历项目。
- 硬约束：投递前 **1 周**、**纯仿真**（投实习不做真机，真机后续阶段再做）、**偏工业岗**、AI 辅助编码。
- **姿态学习明确排除**：已知坑（6D 动作姿态维度无学习信号，`action_space_dim` 6→3 实证教训），姿态奖励塑形 ≥2 周，一周内做 = 半途而废。

## 2. 架构分工（2026-08-24 确认）

| 任务 | 承担者 | 说明 |
|---|---|---|
| 静态避障 + 静态抓取 | **MoveIt2**（OMPL 标称规划） | 经典规划在已知静态世界又快又稳 |
| 动态避障 + 动态抓取 | **RL 残差**（50Hz Servo） | MoveIt 实时动态弱，RL 残差补实时修正 |

- **技术澄清**：动态时 MoveIt 仍生成标称轨迹（对着当前估计的目标位置规划），RL 残差主导实时追踪修正（追移动目标 + 绕移动障碍）。静态世界残差极小，动态世界残差主导。
- 与 `docs/混合控制架构设计.md` 三层架构（MoveIt 静态层 + RL 残差动态层 + 实时安全层）一致。

## 3. 一周渐进式动态（L1/L2/L3）

| 级别 | 场景 | 目标 | 结果定位 |
|---|---|---|---|
| L1 静态闭环（必达，D1-4） | 静态障碍 + 静态目标，残差 RL 绕障抓取 | 成功率 ≥70%、碰撞率 0 | 简历主成果（闭环） |
| L2 动态目标（尽力，D5-6） | 目标物体做简单运动（匀速/往返），RL 追踪抓取 | ≥50% | 加分项（动态归 RL 的直接证据） |
| L3 动态演示（D6-7） | 动态障碍 + 动态目标 | 不做收敛承诺 | 演示视频素材（能力外推） |

## 4. 动态化环境地基（D1 起就位，本周核心工程决策）

1. 障碍物 body 加**可编程运动**（freejoint + step 内 qvel 赋值）：L1 固定、L2/L3 激活——开关切换不返工。
2. 物体位置**可 per-step 更新**（动态目标）：L1 静止、L2 激活。
3. 观测**预留"障碍相对位姿 + 速度"槽位**：L1 占位、L2/L3 填真值——观测空间第一天即最终形态。

## 5. 执行计划（7 天）

- D1：`nominal_trajectory.py`（MoveIt 标称仿真替身）+ `action_mode: 'delta'/'residual'` + step 改 `v = v_nominal(t) + Δv` + 观测加参考速度段 + 动态化地基。
- D2：静态障碍（放标称必经之路，逼 RL 学绕障）+ 机械臂-障碍碰撞检测（仿 `_check_grasp_contact`）+ reward 加障碍接近惩罚 + 残差幅度正则。
- D3-5：按 §11 渐进课程 **S0→S3** warm-start 续训（先迁移 67 维、回归验证、再学绕障）+ 30% 无障碍混合采样防遗忘 + AI 分析 reward breakdown / 成功率曲线调参。
- D6：评估（成功率 / 碰撞率 / 残差幅度）+ 感知噪声测试（目标位置加噪 + 漏检）+ **基线对比**（残差 vs 端到端 vs 纯标称，见 §10.4）。
- D7：成果包装（成功率与轨迹对比图、README、简历 bullet、1-2min 演示视频、CHANGELOG）。

## 6. 验收标准

- L1 含静态障碍抓取 ≥70%、**碰撞率 = 0**。
- L2 动态目标追踪 ≥50%（尽力，不达标记录为部分验证）。
- 残差幅度统计：静态小 / 动态大（**架构分工成立的证据**，最有说服力的面试数据）。
- 感知噪声下成功率下降 <10%。

## 7. 保底方案（保证一周必有成果）

- 若 D5 残差+避障仍不收敛 → 切"感知噪声鲁棒随机抓取"（在已收敛 70% 随机抓取上加噪声重训，改动 = `perception.py` + 观测通道分离，收敛稳得多）。
- 成果叙事降级但仍闭环："带感知噪声的 RL 抓取鲁棒性"。

## 8. 简历叙事

> 混合残差架构（MoveIt 标称 + RL 残差）下的动态抓取避障；纯仿真验证 + sim2real 文档化路线；环境自始为动态设计。命中：残差 RL（工业范式）、避障（安全约束）、感知鲁棒（现实 gap）、动态追踪（动态控制）。

## 9. 风险

- 动态收敛风险：L1 保底闭环、L2/L3 为加分不承诺。
- 6D 姿态学习移出本周（留真机阶段扩展）。

## 10. 简历包装与含金量（2026-08-24 记录）

### 10.1 真功夫 vs Toy 拆解（诚实定位）

**Toy 部分（应承认）**：单场景/单物体/纯仿真/无真实感知通道（oracle 观测）/无 baseline 对比/无 benchmark。

**真功夫部分（不低估）**：
- 失败模式根因诊断（悬停=奖励塑形问题；撞桌=物理执行层单侧推挤）——RL 项目里最稀缺的技能，多数简历项目连"为什么失败"都说不清。
- 最小改动原则（撞桌修复 5 处、不碰已收敛路径）。
- 设计决策有理由（6D→3D、oracle 隔离变量、残差 vs 端到端）。
- sim2real 意识（物理判据 z<0.295、MoveIt2 桥接）。

**定位**：高于"跑通示例/课程项目"的多数申请人，低于"真机/顶会/开源知名项目"的少数。靠诊断深度 + 工程完整性取胜，而非成果炫耀。

### 10.2 简历 bullet（可直接用）

> **混合残差架构机械臂抓取（UR5e · MuJoCo · PPO）**
> - 搭建 UR5e 七轴 + 两指夹爪抓取环境（速度级 IK + 夹爪接触状态机），训练随机位置抓取策略，**确定性评估成功率 ≥70%**
> - 定位并修复两类失败模式："悬停"（诊断：奖励塑形问题，下降边际收益 < 步罚）与"撞下桌面"（诊断：物理执行层单侧推挤，接触力阈值 + 对齐约束 5 处最小改动修复）

**写作原则**：每个 bullet = 数字 + 决策理由 + 结果；动词用"定位/诊断/设计"而非"实现/搭建/训练"。

## 11. 训练课程与防遗忘（D3-5 方法，2026-08-24 记录）

### 11.1 关键事实（D1 已落地，无需重做）
- 观测已扩到 67 维（environment.py `_get_observation`）：末尾 +6 v_nominal[55:61] +3 obstacle_rel[61:64] +3 obstacle_vel[64:67]；delta 模式槽位=0、障碍隐藏时障碍槽位=0。
- 残差模式已实现：`v_raw = v_nominal(t) + Δv`（environment.py:486-492），`nominal_trajectory.reference_velocity` 已接。
- 迁移工具 `scripts/migrate_d1_checkpoint.py`：55→67"输入层手术"（新 12 列权重 0 + obs_rms 先验 0/1），`--verify` 实测 0 差，迁移后行为逐 bit 不变 → **warm-start 技术路已通**。

### 11.2 核心结论
- 残差架构下"抓取+避障一起训" = 在已会抓取基础上**只学绕障增量技能**，训练量非瓶颈（PPO 500k-1M 步 GPU 30-60min）。
- 两个真实风险（须用课程化解）：
  1. **范围泛化**：L1 若直接上完整 workspace_bounds + 障碍 = 同时引入两个新变量 → 收敛难、失败无法归因。
  2. **接近路径改变破坏抓取技能**：障碍逼出分布外接近方向，旧抓取技能（接近→对齐→闭合）可能失效。

### 11.3 渐进课程（每步有"成功率不降"检查点）

| 步 | 内容 | 检查点 |
|---|---|---|
| S0 | `migrate_d1_checkpoint.py --verify` 迁移 Stage2 → 67 维 | 行为 0 差 |
| S1 回归 | 67 维模型 + delta + 无障碍，评估 | 成功率 ≈ 旧值（≥70%） |
| S2 学绕障 | 67 维模型 + residual + L1 静态障碍（**小范围** + 障碍必经之路），warm-start 续训 | ≥70%、碰撞率 0 |
| S3 扩范围 | L1 收敛后才动范围（可选，L2 前准备） | 不破坏 S2 结果 |

### 11.4 防遗忘（混合采样，S2 关键）
- 训练时混入 ~30% 无障碍 episode，防止新任务覆盖旧抓取技能。
- "不够"最常见来源 = **旧技能被覆盖**而非样本不足。

### 11.5 障碍设计原则（L1）
- "逼绕障但不逼改抓取末端"：障碍放 home→pre-grasp 路径中途，远离物体上方最后 ~20cm 接近段。
- 保持 action_space_dim=3（姿态固定朝下顶抓），不做侧向抓取（6D 姿态学习已排除）。

### 11.6 应急降级（S2 不收敛时）
1. 回滚 S1 检查点模型。
2. 降障碍难度：障碍更小 / 离路径更远 / 障碍 episode 比例更低。
3. 奖励渐进：r_obstacle / r_residual 权重从 0 渐增（别一开始就重罚压死抓取奖励）。
